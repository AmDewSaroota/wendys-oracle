วิธีใช้งาน

1. จัดการประเภทเตา

  1. เข้า Dashboard → แท็บ "ประเภทเตา"
  2. กด "+ เพิ่มประเภทเตา"
  3. กรอก ชื่อ (เช่น "เตาชีวมวลปรับปรุง") + รายละเอียด (เช่น "เตาประสิทธิภาพสูง ลดควัน")
  4. กด บันทึก

แก้ไข/ลบ: กดปุ่ม "แก้ไข" หรือ "ลบ" ด้านขวาของแต่ละประเภท

ถ้าลบประเภทเตาที่มีบ้านผูกอยู่ → ระบบจะเตือนจำนวนบ้าน และยกเลิกการผูกให้อัตโนมัติ

3. แก้ไขบ้าน

  1. กดปุ่ม "แก้ไข" ที่บ้านนั้น
  2. เปลี่ยน toggle ครัวเรือน/SME ได้
  3. เปลี่ยนประเภทเตาจาก dropdown ได้
  4. กด บันทึก

4. กรอกความถี่ใช้เตา (ครั้ง/เดือน)

รองรับ 2 วิธี: บันทึกอัตโนมัติ (คลิกออกจากช่อง) + บันทึกทั้งหมด (กดปุ่ม)

  1. แท็บ "กลุ่มตัวอย่าง" → แถบสีฟ้าด้านบน "ความถี่ในการใช้เตา (ครั้ง/เดือน)"
  2. เลือก เดือน จาก dropdown (ย้อนหลังได้ 6 เดือน)
  3. กรอก ตัวเลข ในช่องของแต่ละบ้าน (0-31)
  4. Auto-save: คลิกออกจากช่อง (หรือ Tab) → บันทึกทันที ช่องกะพริบเขียว
  5. หรือ กรอกหลายช่อง → กด "บันทึกความถี่" (เซฟเฉพาะที่เปลี่ยน)
  6. ใต้ช่องแสดง: ชื่อผู้กรอก + วันที่ + จำนวนครั้งแก้ไข (ถ้า >1 ครั้ง)
หมายเหตุ:
• บ้านที่มีเซนเซอร์ → แสดงค่าอัตโนมัติ (กรอกไม่ได้)
• ทั้งครัวเรือนและ SME กรอกได้เหมือนกัน
• ทุกการแก้ไขถูกบันทึกลง audit log (ดูที่แท็บ "ข้อมูล" → "📋 ประวัติความถี่")

4.1 ล็อคเดือน (ป้องกันการแก้ไข)

  1. กรอกครบแล้ว → กดปุ่ม "🔒 ล็อคเดือนนี้" (ข้างปุ่มบันทึก)
  2. เมื่อล็อค: ช่องกรอกทั้งหมดถูกปิด + แสดงสถานะ "🔒 ล็อคโดย ชื่อ วันที่"
  3. ต้องการแก้ → กดปุ่ม "🔓 ปลดล็อค" → ยืนยัน → แก้ไขได้ตามปกติ
การล็อค/ปลดล็อคถูกบันทึกในประวัติกิจกรรม (แท็บภาพรวม)

4.2 ประวัติการแก้ไขความถี่

  1. แท็บ "ข้อมูล" → sub-tab "📋 ประวัติความถี่"
  2. เลือกเดือน + กรองตามบ้าน ได้
  3. ตารางแสดง: วันที่, บ้าน, ค่าเดิม → ค่าใหม่, ผู้แก้ + สถานะล็อคของเดือน

7. ลบทีละหลายรายการ (Batch Delete)

เมื่อมีรายการ >10 จะแสดง checkbox ให้เลือกหลายรายการแล้วลบทีเดียว

  1. เปิดแท็บที่ต้องการ (เช่น "บ้านกลุ่มตัวอย่าง")
  2. คลิก checkbox ที่รายการที่ต้องการลบ หรือ "เลือกทั้งหมด" ที่หัวตาราง
  3. แถบสีแดงปรากฏด้านล่าง → กด "🗑️ ลบที่เลือก" → ยืนยัน
แท็บสิ่งที่ลบผลกระทบ

อาสาสมัครอาสาสมัครปลด volunteer_id จากบ้าน
บ้านกลุ่มตัวอย่างบ้านปลดเซนเซอร์ + ลบความถี่

ระวัง: การลบเป็นแบบถาวร — ข้อมูลที่เกี่ยวข้องจะถูกปลดออกด้วย
