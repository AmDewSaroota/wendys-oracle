## วิธีใช้งาน

### 1. จัดการประเภทเตา

1. เข้า Dashboard → แท็บ **"ประเภทเตา"**
2. กด **"+ เพิ่มประเภทเตา"**
3. กรอก **ชื่อ** (เช่น "เตาชีวมวลปรับปรุง") + **รายละเอียด** (เช่น "เตาประสิทธิภาพสูง ลดควัน")
4. กด **บันทึก**

**แก้ไข/ลบ**: กดปุ่ม "แก้ไข" หรือ "ลบ" ด้านขวาของแต่ละประเภท

> ถ้าลบประเภทเตาที่มีบ้านผูกอยู่ → ระบบจะเตือนจำนวนบ้าน และยกเลิกการผูกให้อัตโนมัติ

---

### 2. เพิ่มบ้านกลุ่มตัวอย่าง

1. เข้า Dashboard → แท็บ **"กลุ่มตัวอย่าง"** → กด **"+ เพิ่มบ้าน"**
2. กรอกชื่อบ้าน
3. **ประเภทกลุ่มตัวอย่าง**: กด toggle เลือก
   - **ครัวเรือน** (น้ำเงิน) — ค่าเริ่มต้น
   - **SME** (ม่วง) — เตาขนาดใหญ่/ร้านค้า
4. **เลือกประเภทเตา**: เลือกจาก dropdown (ประเภทเดียวกันเลือกได้หลายบ้าน)
5. กรอกที่อยู่ / จังหวัด / พิกัด GPS
6. กด **บันทึก**

---

### 3. แก้ไขบ้าน

1. กดปุ่ม **"แก้ไข"** ที่บ้านนั้น
2. เปลี่ยน toggle ครัวเรือน/SME ได้
3. เปลี่ยนประเภทเตาจาก dropdown ได้
4. กด **บันทึก**

---

### 4. กรอกความถี่ใช้เตา (ครั้ง/เดือน)

1. ที่แท็บ **"กลุ่มตัวอย่าง"** → ด้านบนจะมีแถบสีฟ้า "ความถี่ในการใช้เตา (ครั้ง/เดือน)"
2. เลือก **เดือน** จาก dropdown (ย้อนหลังได้ 6 เดือน)
3. กรอก **ตัวเลข** ในช่องของแต่ละบ้าน (0-31)
4. กด **"บันทึกความถี่"**
5. จะแสดง ชื่อผู้กรอก วว/ดด ใต้ช่อง (audit trail)

**หมายเหตุ:**
- บ้านที่มีเซนเซอร์ → แสดงค่าอัตโนมัติ (กรอกไม่ได้)
- แก้ไขได้ตลอด ไม่ล็อค — มี audit trail เห็นว่าใครกรอกล่าสุด
- ทั้งครัวเรือนและ SME กรอกได้เหมือนกัน

---

### 5. แผนที่

- **แผนที่ภาพรวม** (Deep Insights) → hover ที่จุดสี:
  - ชื่อบ้าน, ประเภท (ครัวเรือน/SME), ความถี่, **ประเภทเตา**
  - น้ำเงิน = มีเซนเซอร์
  - เขียว = ครัวเรือน ใช้บ่อย (15+ ครั้ง/เดือน)
  - ส้ม = ครัวเรือน ใช้ปานกลาง (5-14 ครั้ง/เดือน)
  - แดง = ครัวเรือน ใช้น้อย (0-4 ครั้ง/เดือน)
  - ม่วง = SME
- **Preview Map** → เหมือนกัน ใช้สำหรับ export PNG

---

### 6. การแสดงผลในรายชื่อบ้าน

แต่ละบ้านจะแสดง:
- ชื่อบ้าน + ที่อยู่
- ชื่อประเภทเตา (ถ้าผูกไว้) — แสดงใต้ชื่อบ้าน เป็นตัวอักษรสีส้ม
- Badge: ครัวเรือน/SME, สถานะ active/inactive, มีเซนเซอร์/ไม่มี
- ช่องกรอกความถี่ (หรือค่าอัตโนมัติจากเซนเซอร์)

## โครงสร้างข้อมูล

```
subjects (บ้านกลุ่มตัวอย่าง)
├── subject_type: 'household' | 'sme'     ← toggle
├── stove_id → stoves.id                  ← ประเภทเตา (many:1)
└── ...

stoves (ประเภทเตา — หมวดหมู่)
├── name: 'เตาชีวมวลปรับปรุง'
├── description: 'เตาประสิทธิภาพสูง...'
└── created_by, created_at

monthly_usage (ความถี่)
├── subject_id → subjects.id
├── month: '2026-04'
├── usage_count: 15
├── created_by + updated_at               ← audit trail
└── UNIQUE(subject_id, month)
```

**ความสัมพันธ์:**
- 1 ประเภทเตา → หลายบ้าน (many:1) — ไม่ใช่ 1:1
- 1 บ้าน → 1 ประเภทเตา (หรือไม่มี)
- ความถี่ = 1 record ต่อ บ้าน ต่อ เดือน
