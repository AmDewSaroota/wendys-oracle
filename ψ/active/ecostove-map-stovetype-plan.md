# EcoStove — Map + Stove Type + Frequency Plan

**Source**: REQ จาก อ.แก้ว/ทีม (ประชุม 2026-04-20)
**Recorded**: 2026-04-25 (DewS ให้รายละเอียดซ้ำหลัง plan file หาย)
**Status**: รอทำ

---

## 1. กลุ่มตัวอย่าง — 2 ประเภท

### ครัวเรือน (Household)
- ใช้เตาทำอาหาร **เกือบทุกวัน**
- เตาขนาดเล็ก **1-2 เตา** ต่อบ้าน

### SME (เตาขนาดใหญ่)
- ใช้ประมาณ **2-4 ครั้ง/เดือน**
- เตาขนาดใหญ่ **1-10 เตา** ต่อสถานที่

---

## 2. แผนที่ — หน้า Deep Insights

### ข้อกำหนด
- **ไม่ Cluster** — หมุดแยกทุกจุด แสดงพิกัดจริง
- **Export เป็นภาพนิ่ง** สำหรับปริ้นท์ใส่เอกสาร (กดซูมไม่ได้)
- ต้อง **อ่านออกแม้เป็นภาพนิ่ง** — สีชัด จุดไม่ซ้อน
- **Hover** (บนเว็บ) → แสดงรายละเอียดเพิ่มเติม

### สีหมุด — 3 กลุ่ม

| # | ประเภท | สี | สัญลักษณ์ | เงื่อนไข |
|---|--------|-----|----------|----------|
| 1 | บ้านที่มีเตา **+ เซนเซอร์** (ทุกประเภท) | **ฟ้า** | 📡 ดาวเทียม | มี device ผูกอยู่ |
| 2a | ครัวเรือน — ใช้บ่อย | **เขียว** | 🔥 ไฟ | ≥15 ครั้ง/เดือน |
| 2b | ครัวเรือน — ใช้ปานกลาง | **ส้ม** | 🔥 ไฟ | 4-14 ครั้ง/เดือน |
| 2c | ครัวเรือน — ใช้น้อย/ไม่ใช้ | **แดง** | 🔥 ไฟ | 0-3 ครั้ง/เดือน |
| 3 | SME เตาขนาดใหญ่ | **ม่วง** | 🔥 ไฟ | ประเภท SME (ไม่สนความถี่) |

### หมายเหตุสัญลักษณ์
- สัญลักษณ์ (📡/🔥) สามารถ **ลดรูปหรือซ่อน** ถ้ารบกวนภาพนิ่ง
- แค่ **จุดสี** ก็ได้ถ้าอ่านชัดกว่า
- บนเว็บ → **Hover แสดงรายละเอียด** (ชื่อบ้าน, ประเภท, ความถี่, ฯลฯ)

## 3. Admin Dashboard — เพิ่ม 2 อย่าง

### 3a. แท็บเพิ่มเตา (Stove Tab)
- ตำแหน่ง: **หลังแท็บเพิ่มโครงการ**
- แอดมินเป็นคนแอดเตาเอง
- รายละเอียดเตา: ประเภท (ครัวเรือน/SME), ขนาด, จำนวน, ฯลฯ

### 3b. Dropdown ประเภทเตา ตอนเพิ่มกลุ่มตัวอย่าง
- เพิ่ม **dropdown เลือกประเภทเตา** ในฟอร์มเพิ่มข้อมูลกลุ่มตัวอย่าง (subjects)
- ตัวเลือก: ครัวเรือน / SME

---

## 4. Monthly Frequency — ความถี่รายเดือน

- แอดมินกรอก **จำนวนครั้งที่ใช้เตา/เดือน** ต่อบ้าน
- ใช้แบ่งสีหมุดบนแผนที่ (เฉพาะครัวเรือน)
- Batch input — กรอกหลายบ้านพร้อมกัน
