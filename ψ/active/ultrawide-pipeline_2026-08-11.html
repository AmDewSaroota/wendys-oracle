Ultrawide Pipeline

3 ขั้นตอน สู่ Ultrawide

↻

Pipeline นี้ไม่ได้ถูกออกแบบไว้ล่วงหน้า — แต่เกิดจากการปรับวิธีทำงานตามโจทย์ที่เปลี่ยนในแต่ละขั้นตอน แต่ละ step เกิดขึ้นเพื่อแก้ปัญหาเฉพาะหน้า จนกลายเป็น workflow ที่ replicable ได้

01
Higgsfield / Photoshop

สกัด Keyframe → ทำแถบดำที่ภาพนิ่ง → ขยายเป็น Ultrawide

สังเกตจาก prompt และ ref ที่เคยเจนแล้วได้ผล → เลือก keyframe ที่ดีจากคลิป 21:9 / 720P → วางในเสกลที่พร้อมขยาย → นำ frame ไปขยายและใส่แถบดำด้วย Higgsfield หรือ Photoshop ให้กลายเป็น ultrawide still พร้อมแถบดำ

Output: ultrawide starting frame พร้อมแนบ prompt รอบถัดไป
Keyframe สกัดจากคลิป 21:9
Base image · frame ที่เลือกก่อนขยาย
Higgsfield / PSD
ขยาย + ใส่แถบดำ
→
Ultrawide Starting Frame
พร้อมแนบเป็น ref ขั้นถัดไป
HIGGSFIELD PROMPT ตัวอย่าง prompt สำหรับ expand frame → Ultrawide
แนบ frame ที่วางในเสกลที่พร้อมทำเป็น ultrawide แล้ว → Higgsfield อ่าน @Image 1 เป็น base แล้วเติมพื้นที่ดำซ้าย/ขวา
@Image 1 — BASE IMAGE. Lock this frame exactly.
Do not alter center content, lighting, or composition.

Extend the scene outward — fill the black areas on the LEFT and RIGHT
to complete the ultrawide frame. Match existing atmosphere, lighting,
and depth seamlessly. Same environment continuing outward.
No new focal elements — environment extension only.

ULTRAWIDE LETTERBOX. Black bars top and bottom are permanent —
fixed 2D overlay, not part of the scene.
Do not remove, shrink, or warp them.

Film grain, ARRI tone, cinematic depth. Seamless blend at all edges.
· @Image 1 ต้องระบุชัดว่าเป็น BASE IMAGE — ไม่ใช่ ref
· ถ้ามี character ref เพิ่ม @Image 2 แยก — ระบุว่า "appearance reference only"
02
Dreamina Re-Gen

แนบ Ultrawide Ref + Prompt → Re-Gen คลิป

นำ ultrawide still จาก Step 01 แนบเป็น starting frame ref ใน Dreamina พร้อม prompt ที่ล็อคแถบดำ → re-gen คลิป → AI maintain แถบดำตลอด → ได้ ultrawide letterbox clip

Output: ultrawide clip พร้อมนำเข้า AE
PROMPT LOCK กฎล็อคแถบดำ — ใส่ทุกครั้งที่แนบ ultrawide ref
ตัวอย่าง prompt ที่ใช้จริง
ULTRAWIDE LETTERBOX. Black bars top and bottom permanent — never disappear or shrink.
หรือ
CRITICAL: Black bars at top and bottom are permanent throughout — never disappear or shrink.
กฎการใช้
  • ระบุ โดดเด่น ต้นๆ prompt — ไม่ฝังในย่อหน้า
  • ใส่พร้อมกับเรฟแถบดำแล้ว
  • AI มักตีความแถบดำว่า "ข้อผิดพลาด" — ต้องบอกชัดว่าคือ fixed 2D overlay
!
เรฟ frame / BG
ต้องมีแถบดำอยู่แล้วในภาพ — ref แบบ 21:9 เฉยๆ (ไม่มีแถบ) AI จะเจนแบบ 21:9 โดยไม่มีแถบดำ
✓
Character Sheet
แนบได้ปกติทุก format — ไม่กระทบแถบดำ
03
After Effects

AE — ครอปแถบดำ + ปรับ Spec

นำคลิป ultrawide letterbox เข้า AE → ครอปแถบดำบนล่างออก เหลือเฉพาะเนื้อหา ultrawide → ปรับ scale ให้ตรง LED Wall spec

Output: ultrawide clip พร้อม deliver
CASE ปรับ spec กลางโปรดักชั่น

เริ่มต้นได้รับ spec 9,116 × 1,892 — ระหว่างทางได้รับข้อมูลอัปเดตว่าจอจริงคือ 12,288 × 2,160 แก้ใน AE โดยไม่ต้อง re-gen คลิปใหม่ ใช้ 3 layers: คลิปกลาง + ขยายซ้าย + ขยายขวา (inverted mask)
