Part 3

โครงการมีระเบียบวิธี 3 ชั้นเพื่อให้ข้อมูลที่เก็บได้สะท้อนค่ามลพิษจากเตาจริง ๆ ไม่ใช่ค่าจากแหล่งอื่นปะปน

🌬️ ชั้นที่ 1 — Baseline Subtraction (การหักค่า ambient)

ทุก session เก็บค่าอากาศ 10 นาทีแรก ก่อนจุดเตา เป็น baseline — แล้วหักออกจากค่า reading ตอนทำอาหาร เพื่อแยกค่ามลพิษ "จากเตา" ออกจากค่ามลพิษ "ในอากาศปกติ"

⚙️ ชั้นที่ 2 — Sensor Calibration หลังเจอควันเข้มข้น

เมื่อเซนเซอร์เจอควันเข้มข้นเกินขีด ค่าตรวจวัดอาจค้างที่ระดับสูง (sensor saturation) — โครงการกำหนดให้ ปรับเทียบ (กด 4 ครั้ง รอ 120 วินาที) ก่อนเริ่ม session ใหม่ทุกครั้งที่ค่าค้าง

🏠 ชั้นที่ 3 — Sensor Isolation ต่อบ้าน

แต่ละบ้านใช้เซนเซอร์ตัวเดียวอย่างคงที่ตลอดโครงการ — ป้องกันการสับสนของข้อมูล + ลด variance จากความแตกต่างระหว่างเซนเซอร์

A1
Thai AQI — ดัชนีคุณภาพอากาศ
Appendix
Linear Interpolation Formula
AQI = (aqi_hi − aqi_lo) / (pm_hi − pm_lo) × (PM2.5 − pm_lo) + aqi_lo
ตัวอย่าง
PM2.5 = 30 µg/m³
อยู่ในช่วง [25.1, 37.5] → AQI [51, 100]
AQI = (100 − 51) / (37.5 − 25.1) × (30 − 25.1) + 51 ≈ 71

Daily Aggregations — การรวมข้อมูลรายวัน
Appendix

ข้อมูลที่เซนเซอร์ส่งทุก 5 นาที (สูงสุด ~52 จุด/วัน) ถูกนำมารวมเป็นค่ารายวันแยกตามบ้านและประเภทเตา

Operations
average = sum / count min = cumulative Math.min max = cumulative Math.max count = จำนวน reading ที่ไม่เป็น null
ตัวอย่าง — PM2.5
5 readings: [42, 65, 88, 71, 50]
sum = 316 · count = 5
average = 63.2 µg/m³ · min = 42 · max = 88
การจัดการข้อมูลที่ขาดหาย: Reading ที่เป็น null จะไม่ถูกนับใน count — ค่า average จึงสะท้อนข้อมูลที่มีอยู่จริง ไม่ถูกบิดเบือนโดยค่าศูนย์

Session Detection Logic — การตรวจจับสถานะเซสชัน
Appendix

ค่าคงที่ของระบบ

ParameterValueคำอธิบาย
SESSION_MAX_MINUTES130ความยาวสูงสุดของ 1 session (2 ชม. 10 นาที)
SESSION_COOLDOWN_MINUTES300ระยะเวลาพักระหว่าง session (5 ชม.)

State Machine

baseline (10 min) ↓ collecting (active session) ↓ complete / incomplete / cancelled ↓ cooldown (5 hours) ↓ new-session (กลับสู่ baseline) หรือ daily-limit (ถ้าเก็บครบ 2 sessions แล้ว)
Decision tree: หากมี active + เกินเวลา → auto-cutoff · หาก cooldown ยังไม่หมด → ยังไม่ให้เริ่ม · หากเก็บครบ 2/วัน → daily-limit
A4
Eco vs Old Stove % — การคำนวณการลดมลพิษ
Appendix
กรณีปกติ — เตา biomass ลดมลพิษได้
Reduction % = (oldAvg − ecoAvg) / oldAvg × 100
ตัวอย่าง
oldAvg = 50 µg/m³ (PM2.5 ของเตาเดิม)
ecoAvg = 15 µg/m³ (PM2.5 ของเตา biomass)
Reduction = (50 − 15) / 50 × 100 = 70%
กรณีพิเศษ — เตา biomass ไม่ลด (ecoAvg ≥ oldAvg)
Increase % = (ecoAvg − oldAvg) / oldAvg × 100
การแสดงผล
แสดงเป็นเครื่องหมาย ↑ พร้อม % เพิ่มขึ้น (ไม่ใช่ลดลง)
เพื่อความโปร่งใสในการรายงานข้อมูล

A5
Baseline Subtraction — การหักค่า ambient
Appendix

ระเบียบวิธีนี้แยกค่ามลพิษ "จากเตา" ออกจากค่ามลพิษ "ในอากาศปกติ" ของห้องครัว — เพื่อความถูกต้องในการประเมินผลกระทบของเตา

Cooking Phase Value
cookingValue = max(0, rawValue − baseline_avg)
ตัวอย่าง — PM2.5
baseline_avg = 18 µg/m³ (ค่าอากาศ 10 นาทีก่อนจุดเตา)
rawValue = 65 µg/m³ (ค่าขณะทำอาหาร)
cookingValue = max(0, 65 − 18) = 47 µg/m³

✅ พารามิเตอร์ที่ใช้ baseline

PM2.5 · CO₂ · อุณหภูมิ · ความชื้น

❌ ไม่ใช้ baseline

CO · TVOC · HCHO (manual entry only)
Edge cases: หาก baseline_avg = null → ใช้ rawValue ตรง ๆ · หาก rawValue < baseline → floor เป็น 0 (ไม่อนุญาตค่าติดลบ)

A7
การรวมข้อมูล Manual กับ Sensor
Appendix

ข้อมูล TVOC และ CO ที่อาสาสมัครบันทึกด้วยตนเอง รวมเข้ากับข้อมูลจากเซนเซอร์โดยไม่มีการแปลงหน่วยหรือ scaling — สมมติว่าหน่วยตรงกัน

Combined Average
tvoc_avg = (tvoc_sensor_sum + tvoc_manual_sum) / (count_sensor + count_manual)
หมายเหตุ
- ระบบ tag ที่มาของข้อมูลแต่ละจุด (source = sensor หรือ source = manual)
- ใน session summary แสดง label "sensor + manual" หรือ "manual only" ตามแหล่งที่มา
- ไม่มี scaling/conversion — ข้อมูลถูกใช้แบบ raw
ข้อจำกัด: ระบบยังไม่มี Quality Control layer สำหรับข้อมูล manual — ต้องอาศัยอาสาสมัครบันทึกค่าให้ตรงตามที่อ่านจากหน้าจอเซนเซอร์ การฝึกอบรมและการตรวจสอบเป็นระยะจึงสำคัญมาก
