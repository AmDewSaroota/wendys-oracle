## Lessons Learned
- **`disable-model-invocation: true` ใน skill frontmatter = สกิลถูกซ่อนจาก slash menu + model list** ใน 環境 Claude Code นี้ ถ้าอยาก user-invoke ได้ ห้ามใส่ field นี้ ใช้แค่ `user-invocable: true`
- เพิ่มสกิลใหม่กลาง session → `grilling` (model-invocable) โผล่ทันทีในระบบ แต่ **slash `/command` ต้อง Reload Window** ถึงจะขึ้นในเมนู
- เจออาการสกิลไม่ทำงาน → diff กับสกิลที่ใช้ได้จริง (hello-wendys) ก่อนโทษ cache/reload
