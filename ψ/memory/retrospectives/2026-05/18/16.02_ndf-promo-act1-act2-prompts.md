## Lessons Learned

1. **Seedance time code = cut point** — ถ้าอยากได้ continuous shot ต้องรวมเป็น block เดียว ไม่แบ่ง timestamp และระบุว่าเป็น physical camera movement (crane/dolly)
2. **Visual signature ของ genre** — บอก "เกมงู" ไม่พอ ต้องบอก DNA: สายยาวเลี้ยว, top-down, ไล่กัน — ไม่ใช่ตัวละครยืนสู้
3. **Full prompt เสมอ** — Seedance workflow = copy-paste ทั้งหมด ไม่มี partial update
