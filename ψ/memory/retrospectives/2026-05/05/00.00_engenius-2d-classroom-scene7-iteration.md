## Lessons Learned

- **Character description ใน prompt สำคัญกว่า ref image** — Nanobanana Pro ไม่ follow ref 100% ต้องเขียนรายละเอียด (สีผม, ทรงผม, สีตา, เสื้อผ้า) ใน text ด้วยเสมอ
- **เปลี่ยนคอนเซ็ปต์ = เริ่ม prompt ใหม่** — อย่า patch prompt เก่า เริ่มจากศูนย์ดีกว่า
- **บริบทของซีนสำคัญ** — "ทำแบบทดสอบแล้วสงสัย" ดีกว่า "นั่งโต๊ะแล้วถาม" เพราะมีเหตุผลรองรับ
