## Lessons Learned

- `pollution_logs.status = 'pending'` คือ "รออนุมัติ" ใน Biomass system — ไม่มี pending table แยก
- DELETE order ตาม FK: child tables ก่อน parent เสมอ (pollution_logs → sessions → subjects)
- Claude Code VSCode extension 2.1.128 ไม่มี setting ปิด auto-open files
- ตรวจ extension `package.json` ก่อนให้คำแนะนำ — อย่าเดาชื่อ setting
