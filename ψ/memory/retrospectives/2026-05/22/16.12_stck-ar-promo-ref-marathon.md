## Honest Feedback

**1. UI Circular Portal ผิดตั้งแต่ต้น**: เขียน prompt UI แล้วได้ circular viewport แบบกล้องส่องทางไกล ซึ่งไม่ใช่ AR เลย ควรระบุตั้งแต่แรกว่า "no circular frame, no portal, full camera viewfinder" — การไม่ห้ามชัดทำให้เสียรอบการ gen ไปหลายรอบ

**2. REFA dominance ไม่ได้เตือนล่วงหน้า**: รู้ว่า ref ดึง composition มาแล้วจากประสบการณ์ Engenius session แต่ยังแนะนำให้แนบ REFA ใน people shots โดยไม่เตือนว่ามันจะ lock pose ด้วย DewS ต้องแก้เองหลายรอบก่อนเราจะ drop ref ออก

**3. AR model อยู่นอกจอ — ปัญหาเดิมไม่หาย**: ทุก session ที่เกี่ยวกับ AR รู้ว่า Dreamina/Seedance ชอบทำ hologram ลอยในโลกจริง แต่ยังไม่มี fix ที่แน่นอน "model only visible on phone screen — NOT floating in real world" ช่วยได้บางส่วนแต่ไม่ 100%

## Lessons Learned

- **REFA ใน people shots = lock pose** — แนบเฉพาะ component ref เท่านั้น บรรยาย setting ใน text
- **Dreamina circular portal default** — ต้องห้ามตรงๆ: "no circular frame, no portal, no scope effect"
- **AR model ลอยนอกจอ** — ต้องเขียน "NOT floating in real world — only visible on phone screen" ทุกครั้ง
- **Metaphor shot vs AR shot** — ต่างกันชัด: metaphor = model ลอยในฉากแต่ตัวละครไม่รับรู้; AR = model อยู่บนหน้าจอเท่านั้น
- **Classroom_REF แยก** — ถ้าต้องการห้องเรียน consistent ต้องเจน empty classroom ref ก่อน
