## Honest Feedback

**1. Demo game wording ต้องแก้หลายรอบ**
ครั้งแรกเขียนว่า "เลือก 1 theme" ซึ่งผิดทิศ เพราะ DewS ไม่อยากให้ลูกค้า lock theme ตั้งแต่ใบเสนอราคา ควรคิดให้รอบคอบกว่านี้ก่อนเขียน — ถ้าเข้าใจ intent ของ DewS ดีกว่านี้ตั้งแต่แรก ก็ไม่ต้องแก้

**2. ราคา training ต่างกันระหว่าง 2 plan**
Plan A training = 50,000, Plan B = 40,000 ซึ่งอาจสร้างความสงสัยได้ว่าต่างกันยังไง ควรอธิบาย rationale ให้ชัดกว่านี้ว่า Plan B มี marker-specific training ที่ต้องอธิบายเรื่อง layout precision แต่ถ้า scope ใกล้เคียงกัน อาจควรเท่ากันไปเลย

**3. ยังไม่มี payment milestone schedule**
ใบเสนอราคาแสดง grand total แต่ไม่มี breakdown ว่าจ่ายงวดไหนเท่าไหร่ สำหรับโปรเจกต์ ~10 สัปดาห์ ควรมี milestone payment (เช่น 30% เซ็นสัญญา, 40% ส่งมอบ SDK, 30% POC เสร็จ) ค่ะ

## Lessons Learned
- SSA = ผูกกับ physical environment, Marker = ผูกกับ marker set → เลือกตาม requirement ว่า "ย้ายที่ได้" สำคัญกว่า "ไม่มีป้าย" หรือเปล่า
- Hardware add-on ต้องรู้ compute layer ก่อน ถึงจะ price ได้ถูกต้อง
