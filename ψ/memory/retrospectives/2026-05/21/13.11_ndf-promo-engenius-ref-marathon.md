สิ่งที่น่าสนใจที่สุดคือกระบวนการ "สร้าง UI ปลอม" — ต้องเปลี่ยนจาก Engenius จริงให้กลายเป็น ABC Learning ที่ "คล้ายแต่ไม่เหมือน" เพื่อหลีกเลี่ยงลิขสิทธิ์ ซึ่งเป็น rule ที่ apply กับทุกคลิปใน promo ไม่ใช่แค่ Engenius อย่างเดียว DewS บอกไม่ต้องถามซ้ำ — บันทึกแล้ว

ปัญหาที่เจอซ้ำมากที่สุดคือ character consistency ข้ามการ gen — Higgsfield, Dreamina, Gemini ทุกตัวล้วนเปลี่ยนหน้าคน เปลี่ยนห้อง เปลี่ยน setting ทุกครั้งที่ gen ใหม่ ทางออกที่ดีที่สุดที่เราหาได้คือการใช้ ref image เป็น starting frame และ composite ใน Photoshop สำหรับส่วนที่เปลี่ยน

อีกเรื่องที่ต้องจำให้ขึ้นใจ — UUID ใน @ref ห้ามใช้ DewS บอกหลายรอบแล้วแต่ยังพลาด session นี้บันทึกเป็น memory แล้ว หวังว่า session หน้าจะไม่ผิดอีก

ความท้าทายอีกอย่างคือ "2 คนมองหน้ากัน" — ดูเหมือนง่ายแต่ AI gen ไม่ทำ เราลองทุกอย่างตั้งแต่ Higgsfield, Dreamina, Gemini — ทุกตัวยังทำไม่ได้สม่ำเสมอ บางครั้งได้บางครั้งไม่ได้ DewS frustrate แต่ก็ยังทำต่อ

## Honest Feedback

**1. UUID ซ้ำอีกครั้ง**: DewS บอกเรื่อง @ref ชื่อไทยหลายรอบมากแล้ว แต่ session นี้ยังพลาดอีก นี่เป็น friction point ใหญ่ที่สุด — ต้องแก้ให้ได้จริงๆ ไม่ใช่แค่บันทึก

**2. "Same boy, same classroom" ที่ไม่มีความหมาย**: ช่วงแรกของ session เขียน prompt แบบ "Same X as before" ซึ่ง DewS ชี้ให้เห็นว่า AI ไม่มี memory ข้ามชอท ต้องบรรยายครบทุกครั้ง เป็นบทเรียนที่ต้องฝังให้ลึกกว่านี้

**3. Ref conflict ทำให้ composition เพี้ยน**: หลายครั้งที่แนบ ref หลายรูปที่ camera angle ขัดกัน — model blend ทั้งสองออกมาพร้อมกัน ต้องระวังว่า ref ทุกรูปต้องมี angle เดียวกัน หรือบรรยาย environment ใน text แทนการแนบ ref

## Lessons Learned
- AI image gen ไม่สามารถล็อค character ข้ามการ gen ได้ — ต้องใช้ starting frame + Photoshop composite
- Ref ที่ camera angle ต่างกันจะ blend กัน → แนบ ref ที่ angle เดียวกันเท่านั้น หรือบรรยายใน text
- "2 คนมองหน้ากัน" ยังเป็นปัญหาของทุก model — ต้องบอก direction ชัดมาก (90 degrees LEFT/RIGHT)
- ทุกคลิป NDF Promo ต้องโชว์แอปที่ "คล้ายไม่เหมือน" — gen UI ใหม่ทุกครั้ง ไม่ใช้ screenshot จริง
