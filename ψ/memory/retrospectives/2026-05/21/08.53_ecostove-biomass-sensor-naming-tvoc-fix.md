## Honest Feedback

**Friction 1 — Naming Convention Debt ยังค้างอยู่**
วันนี้ fix เป็น warning ซึ่งดีกว่าไม่มีอะไร แต่ root ยังอยู่: admin ยัง type เลขเองได้ ถ้า long-term solution คือ "เลขมาจาก sensor record" ก็ควร track เป็น proper task ไม่ใช่แค่ next step ในไฟล์ retro ที่จะถูกลืม

**Friction 2 — Bug พบจาก production testing ไม่ใช่ unit test**
TVOC bug และ mismatch bug ทั้งคู่ถูกพบจากการลอง use จริง ซึ่งดีที่ DewS ทำ แต่หมายความว่าไม่มี automated safety net อยู่เลย ถ้ามี regression ในอนาคตจะรู้ได้ยากถ้า DewS ไม่ได้ทดสอบ

**Friction 3 — showAutoSessionSummary + pollTimer coupling ยังเปราะ**
fix ที่ทำคือ return; ซึ่งถูกต้องสำหรับ case นี้ แต่ logic ใน poll function ยังมี multiple branching paths ที่ dependent กัน ถ้ามี case ใหม่ในอนาคต คนที่ไม่รู้ history อาจทำให้เกิด bug คล้ายกันได้อีก

## Lessons Learned

`clearInterval` ใน function ที่ถูกเรียกจาก callback ไม่หยุด execution ของ callback ปัจจุบัน — ต้อง `return` ในสายที่เรียกเองเสมอ
