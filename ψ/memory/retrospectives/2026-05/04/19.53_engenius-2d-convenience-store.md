## Honest Feedback
1. **Image prompt ไม่ได้คำนึงถึง video prompt ตั้งแต่แรก** — ฉันเขียน image prompt ให้ตัวละครถือของ แต่พอเขียน video prompt กลับสั่งให้ชี้ ควร plan ทั้ง pipeline (image → video) ตั้งแต่ต้น ไม่ใช่คิดแยกส่วน

2. **Pose complexity ไม่ได้ test ก่อนส่งทุก scene** — รู้ว่า Scene 4 เพี้ยนเพราะท่ายาก แต่ไม่ได้ไปแก้ scene อื่นที่อาจมีปัญหาเดียวกันทันที ควร apply fix เป็น batch ทุก scene

3. **Video prompt ใช้ 舔嘴唇 ใน chat แต่ HTML ไม่มี** — เกิด confusion ว่า DewS ก้อปจากไหน ควรชี้ชัดว่า "ก้อปจาก HTML เท่านั้น อย่าก้อปจาก chat" ตั้งแต่แรก

## Lessons Learned
1. **2D flat style = simple poses only** — pointing, clapping, looking, waving. ห้าม holding complex props
2. **Explicit foreground/background** — ต้องบอก "characters in foreground, clearly in front of [X]"
3. **Video prompt must match ref image** — ถ้าภาพถือของ ห้ามสั่งชี้ ถ้าภาพมือว่าง ถึงสั่งชี้ได้
4. **Plan image+video prompts together** — คิดว่า video จะให้ทำอะไร ก่อนเขียน image prompt
