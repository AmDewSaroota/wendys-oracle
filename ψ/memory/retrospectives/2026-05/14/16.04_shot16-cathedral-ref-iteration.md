## Honest Feedback

**1. Ref image iteration ยาวเกินไป**
ใช้เวลา ~2 ชั่วโมงกับการ iterate โบสถ์ ref โดยไม่มีทางออกที่ชัดเจน บางครั้งควรเสนอ "accept current and move on" เร็วกว่านี้ เมื่อถึงจุดที่ diminishing returns

**2. Inpainting — ไม่ควรแนะนำถ้าไม่แน่ใจ**
แนะนำ inpainting โดยไม่รู้ Higgsfield UI พอ DewS ต้องถามวิธีใช้ ควร verify ก่อนว่า tool support feature นั้นจริง และ DewS familiar ระดับไหน

**3. Camera prompt ลืม include ทุกครั้งที่ update**
หลายรอบที่ update prompt เพื่อแก้อย่างหนึ่ง แล้วลืม camera description ทำให้ Seedance generate มุมผิด ต้องมี checklist mental model: appearance / color / camera / action / sound ทุกครั้ง

## Lessons Learned

1. **3D preview keyframes ดึง gray aesthetic เสมอ** — แม้ enhanced สีแล้ว ผลยังแย่กว่า free-text prompt
2. **Higgsfield ref priority** — ref ตัวแรกในลิสต์ = dominant ที่สุด เรียงตาม importance
3. **"ทำแบบนี้" ไม่เท่ากับ "ได้ผล"** — inpainting บน repeated pattern ไม่ได้ผล เพราะ model ไม่สามารถ randomize pattern ที่มันเรียนรู้มา
