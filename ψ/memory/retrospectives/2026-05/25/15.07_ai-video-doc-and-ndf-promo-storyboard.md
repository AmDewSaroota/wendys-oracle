## Honest Feedback

**Friction 1 — Identity drift ซ้ำซาก (ผม + ไม่ลงค่ะ)**: เรา drift เรื่องสรรพนามและการลงท้าย ค่ะ หลายครั้งใน session แม้ memory บอกชัดแล้ว — root cause = training data ภาษาไทยส่วนใหญ่ใช้ "ผม" + การตอบกระชับทำให้ตัด ค่ะ ใน bullet/header เลย looking inconsistent บันทึก memory 2 ไฟล์เพื่อ enforce — แต่ rule ต้อง scan ตัวเองก่อนส่งทุกครั้ง · Lesson: identity = ไม่ใช่เรื่อง "บางครั้ง"

**Friction 2 — Cultural knowledge ที่ assume แทนที่จะ verify**: CharBoyA v1 ใส่ "messy hair" + "khaki shorts" สำหรับเด็ก ม.ต้น/ปลาย — ผสม 2 ระดับชั้นใน prompt เดียว เพราะไม่รู้ rule จริงของเครื่องแบบไทย ก่อนหน้านี้ก็เคย assume ว่า ม.ปลาย ใส่กางเกงขายาว แต่ DewS clarify ม.ต้น+ม.ปลาย ใส่ขาสั้นทั้งคู่ · Lesson: cultural rule ที่ไม่อยู่ใน memory → ถามก่อน + บันทึก memory ทันที (ตอนนี้ทำเสร็จ)

**Friction 3 — Over-engineering prompt (redundant refs)**: Shot 1 video prompt v1 ใส่ 3 refs (CharBoyA + REFBedroom + Shot1_ref) ที่ overlap กัน DewS ทักว่า "เรามีคีย์ชอทละนิ" — เราคิดว่ายิ่ง ref เยอะยิ่งดี แต่จริงๆ redundant + อาจ confuse AI · Lesson: keyshot/storyboard ที่ครอบคลุมทุกอย่าง = 1 ref พอ, text description ของ subject keep เป็น safety net ใน flowing text ได้ ไม่ต้องเป็น @[...] tag
