## Honest Feedback
**Friction 1: ไม่ stop Clip A ให้ทัน**
DewS เผาเครดิตกับ Clip A มากกว่าทุก clip รวมกัน ฉันควร cap ไว้ที่ 3-4 attempts แล้วบอกว่า "เอา take ที่ดีที่สุดที่มีไปก่อน" แทนที่จะ iterate ต่อเรื่อยๆ

**Friction 2: ไม่เตือน ref contamination ล่วงหน้า**
ทุกครั้งที่มี character อยู่ใน UI ref ฉันควรเตือนก่อนว่า character นั้นจะ leak เข้า generation พี่เหลืองเป็นตัวอย่างชัดเจน — รู้ปัญหาแต่ไม่พูดก่อน

**Friction 3: Clip D concept วน นานเกินไป**
Keyframe approach คือ answer ที่ถูกต้อง แต่มาถึงช้ามาก ผ่าน concept ที่ fail ไป 4 รอบก่อน ถ้า propose keyframe ตั้งแต่รอบที่ 2 จะประหยัดได้มาก

## Lessons Learned
- **Seedance ref contamination**: ทุก ref image ที่มี character อยู่จะ leak character นั้นเข้า generation — ต้องเตือนก่อนใช้เสมอ
- **Credit cap per clip**: ควรกำหนด max attempts ต่อ clip แล้ว commit กับ best take ที่มี
- **Keyframe first**: สำหรับ complex scene ที่มี specific composition — เจน image keyframe ก่อนเสมอ แล้วค่อยทำวิดีโอ
