## Honest Feedback

**1. Brief ไม่ stable ตั้งแต่ต้น** — เราทำ cinematic AI video ไปทั้ง session แล้วพี่บอยถึงบอก "ไม่เหมือนงานจริง" ควรถาม tone/style ให้ชัดก่อน gen ครั้งแรก ไม่ใช่รอให้ผลออกมาแล้วค่อย pivot

**2. Copyright threshold ยังไม่ชัด** — เราเปลี่ยน elephant → butterfly → underwater fish แต่ยังไม่รู้ว่า "ใกล้เคียงพอ" คืออะไรกันแน่ ต้องให้ DewS/พี่บอย approve ทุก theme เปลี่ยน

**3. Seedance ref dominance** — ref ภาพมีอำนาจเหนือ text prompt มาก ถ้า ref เป็น forest Seedance จะ gen forest เสมอ ต่อให้ negative prompt ชัดแค่ไหน การเปลี่ยน ref คือ solution ไม่ใช่แค่เพิ่ม negative prompt

---

## Lessons Learned

1. **Real footage style = credibility + copyright safety** — ดูเหมือนถ่ายจากมือถือ → น่าเชื่อถือกว่า AI cinematic และไม่ต้องพยายาม "ทำให้ต่าง" มากเพราะ context real อยู่แล้ว
2. **Ref image dominates prompt** — เปลี่ยน ref ดีกว่าเพิ่ม negative prompt ถ้า ref ผิด theme prompt ถูกก็แพ้
3. **Hex code = on-screen text** — ห้ามใช้ #XXXXXX ใน Seedance prompt ต้องเป็นชื่อสีเสมอ
