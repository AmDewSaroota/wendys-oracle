## Honest Feedback

**1. Pattern: mockup-from-imagination** — ฉันยังคงสร้าง UI mockup จากการคาดเดา ไม่ใช่จากการอ่านโค้ดจริง ทุกครั้งที่ DewS ตรวจเจอผิด → คิดเอา ไม่ใช่ verify มันคือ habit ที่ต้องเปลี่ยน ก่อนทำ workshop assets ต้อง grep + read source code ทุก field ที่จะ render

**2. Memory drift = remind ผิด** — ฉัน remind "ผูกเซนเซอร์ ค้าง" ที่จริงๆ ทำแล้ว DewS ต้องบอกให้เช็ค → MEMORY.md เก่า → ห้าม trust memory ตอน listing pending → ต้อง verify ก่อนรายงาน

**3. CSRF advice — bait-and-switch** — ตอนแรกบอก DewS ว่า GET→POST จะแก้ CSRF ทั้งที่ระบบไม่มี auth = ไม่ใช่ CSRF เลย พอ DewS ถาม "เธอแนะนำว่าไง" ฉันก็ตอบ "แก้เลย" จริงๆ ควรอธิบายเหตุผลที่ถูกต้องตั้งแต่แรก (refresh-resubmit + prefetch + history leak) ไม่ใช่ CSRF buzzword

**4. Workshop UX — implicit ≠ helpful** — implicit answer เมื่อกด resume ระหว่าง TVOC question pause = ดูเหมือนช่วย user แต่จริงๆ ทำให้ flow ผ่านไปโดยไม่ตั้งใจ workshop ต้อง explicit ทุกการตัดสินใจ — ห้าม "magic" ที่ user ไม่รู้ตัว

**5. ข้อมูลใน volunteer.html เองก็มี bug** — calibrate "3 ครั้ง รอ 2-3 นาที" ใน stall-modal ผิด (ที่อื่นใน repo เขียน 4 ครั้ง 120 วิหมด) — DewS ตรวจเจอเพราะเขาทำงานกับ MT15 จริง — ฉันก็ migrate bug จาก source ไป mockup โดยไม่ verify cross-reference

## Lessons Learned

- **Workshop mockup = mirror of production, ไม่ใช่ design** — grep + read source ทุก field ก่อน render
- **trust DewS เมื่อเขาบอกของจริง** — เขาเป็น domain expert, ฉันแค่อ่านโค้ด
- **Playwright HEAD request mock**: `route.fulfill()` ไม่ส่ง `Content-Range` header กลับเสมอไป → ใช้ `page.addInitScript` override `window.fetch` เป็น escape hatch
- **POST + body refactor**: รองรับทั้ง body + query (`getParam` fallback) ทำให้ deploy แยก backend/frontend ปลอดภัย ไม่ต้อง atomic
- **Auto-pause UX**: ห้าม implicit choice ผ่าน resume button — hide buttons ทำให้ explicit
- **Cross-reference repo เพื่อหา canonical value** — calibrate count ผิดใน volunteer.html แต่ที่อื่นใน repo (training, sticker-guide, index, guide-volunteer) ถูกหมด → grep ก่อนเชื่อ source เดียว
- **MEMORY.md decay** — verify pending TODO กับ source-of-truth ก่อนรายงาน, ห้าม remind ตามที่จำได้
