## Honest Feedback

**Friction 1 — Default to "rebuild" instead of "reuse"**
ครั้งแรก response form หนูเลือก rebuild HTML ทั้งหมด ทั้งที่มี PDF original อยู่แล้ว · ถ้าหยุดถามตัวเองก่อน "มี artifact ที่ใช้ได้เลยไหม?" จะเลือก image overlay ตั้งแต่แรก

**Friction 2 — Apply user's literal numbers without sanity check**
DewS บอก "+10/-15%" หนูใส่ literal แล้วผลพังมาก · ควรเตือนก่อน "15% บนหน้าจอ A4 = ขยับ 165px = เยอะมาก ขอ confirm?"

**Friction 3 — Documentation iteration cycles**
system-demo iteration หลายรอบมาก (basic map → no-old → methodology position → session timeline pagination → stacked bar → no-old content → map markers → wording) · ถ้า audit production overall ก่อน build รอบเดียว ก็จะเสร็จในรอบเดียว แทน 8+ รอบ

## Lessons Learned

1. **Image overlay > Rebuild** — สำหรับ replicate document/page ที่มี original — extract image แล้ว overlay text/elements ดีกว่า rebuild HTML 10 เท่า
2. **PyMuPDF `get_text('dict')`** — ให้ bbox จริงของ text spans → overlay precise pixel-perfect
3. **Sanity-check user numbers** — ก่อนใส่ค่าใหญ่ๆ ที่อาจะ overshoot ตรวจ context (15% บน A4 = ลึกเกิน) → เตือน user ก่อน apply
4. **Audit before build** — สำหรับ UI matching project, ตรวจ source-of-truth ทั้งหมดก่อน build ทีเดียว ไม่ใช่ build แล้ว fix ทีละอัน
5. **DewS's framework**: ถามคำถามดีกว่าให้คำตอบ — "ทำไมต้องทำแบบนี้?" บางครั้งเป็น hint ของวิธีที่ดีกว่า
