## Honest Feedback

**1. Emoji platform difference — ควรรู้ก่อน**: ตอนที่ DewS บอกว่า "เปลี่ยนเป็นสีเหลือง" ฉันทำ SVG ให้ แต่ DewS ไม่ชอบ SVG แล้วก็วนไปที่ emoji ซึ่งสุดท้ายก็คือปัญหา platform rendering ควรอธิบายเรื่อง emoji color variation ตั้งแต่แรกก่อน implement ไม่ต้อง iterate หลายรอบ

**2. Memory drift ระหว่างเครื่อง**: feedback "เปิด Explorer หลังสร้างไฟล์" มีที่พี่เวนดี้แล้วแต่ไม่ได้ sync มา การ sync memory ระหว่างเครื่องยังเป็นจุดอ่อน ฉันควรเช็ค global-memory อย่างละเอียดกว่านี้ตอน session start

**3. PDF iteration loop**: แก้ guide แล้ว deploy แล้ว generate PDF แล้วเจอปัญหาใหม่วนซ้ำหลายรอบ ถ้า preview PDF แบบ local ก่อนได้ก็จะลดรอบได้มาก แต่ Edge headless ต้องใช้ URL จริง ทางออกอาจเป็น `file://` path แทนก็ได้

## Lessons Learned

- `touch-action: manipulation` บน button/[onclick] แก้ 300ms click delay บน mobile ได้โดยไม่ต้องพึ่ง user-scalable=no
- emoji color ขึ้นกับ OS font — Samsung เหลือง, Windows/iOS ฟ้า — ไม่มีทาง CSS override ได้
- เปิดตัว setInterval ที่ module level (activePollFn) แทนที่จะ closure ใน function — ทำให้ other functions call ได้
- inject fake Supabase rows ผ่าน REST API ด้วย service key เพื่อทดสอบ edge case ได้ทันทีโดยไม่ต้องรอ real data
