## Honest Feedback

**1. ดู ref ไม่ละเอียด → บอก DewS ผิด**
DoctorRefA มีฟอร์เซปชัดเจน แต่บอกว่าเป็น syringe DewS ต้องมาแก้ให้ ไม่ควรเกิดขึ้น ต้อง describe visual elements ใน ref ให้ถูกก่อนเขียน prompt เสมอ

**2. เปลี่ยน prompt โดยไม่มีเหตุผลจริง**
เปลี่ยน forceps → stethoscope เพราะกลัว filter ทั้งที่ ref ผ่านแล้ว ถ้า ref ผ่าน Higgsfield แล้ว video prompt ควรใช้คำเดียวกัน ไม่ต้อง second-guess

**3. Minimum duration ลืมซ้ำ**
เขียน 3s อีกครั้งทั้งที่รู้ว่า minimum 4s — ต้องตั้ง habit check duration ทุกครั้งก่อน output

## Lessons Learned

1. **ถ้า ref ผ่าน storyboard แล้ว → prompt video ใช้คำเดียวกันเลย** ไม่ต้องเปลี่ยน instrument/element ด้วยเหตุผล filter ที่ยังไม่เกิด
2. **Video prompt ต้อง "drop into action" ไม่ใช่ "start then move"** — เขียนว่า action กำลังเกิดแล้วตั้งแต่ frame 0
3. **Describe ref ก่อนเขียน prompt** — ระบุให้ได้ว่า object ในรูปคืออะไรแน่ๆ ก่อนใส่ใน prompt
