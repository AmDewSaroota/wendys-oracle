## Honest Feedback

**1. Storyboard camera ไม่มีชีวิต**
prompt เน้น "what" (ท่าทาง controller สถานที่) แต่ไม่ได้กำหนด "how the camera sees it" — angle, energy, tension ใน frame ไม่ชัด ทำให้ Higgsfield gen ออกมาเหมือน passport photo ทุกครั้ง ต้องเพิ่ม cinematic intent ใน storyboard prompt ด้วย

**2. Iterate ช้าเพราะ prompt ไม่ specific พอตั้งแต่ต้น**
Shot 4-BoyBooth ใช้ 7 iterations เพราะแต่ละรอบแก้ทีละจุด แทนที่จะ nail ทุก element พร้อมกัน ถ้ามี reference ภาพ controller จริงตั้งแต่ v1 จะประหยัดได้อย่างน้อย 3 rounds

**3. Naming ไม่ consistent — Shot 3b vs Shot 4-BoyBooth**
เริ่มใช้ Shot 3b แล้วก็เรียก Shot 4 สลับกันไปมา ทำให้ shots.md ยังไม่ได้ update สถานะ Shot 3b อย่างเป็นทางการ

## Lessons Learned

1. **Storyboard prompt ต้องมี camera direction เสมอ** — ไม่ใช่แค่บอก "what is in the scene" แต่ต้องบอก "how camera sees it" — angle, energy, implied motion
2. **ขอ real reference ก่อน เมื่อมี props จริงใน scene** — ถ้ามี physical object (controller, headset, instrument) ขอรูปถ่ายจริงก่อนเขียน prompt จะประหยัด iterations
3. **VR world clips ต้องเจนก่อนเสมอ** เพราะ booth screen content ต้องแมชกับสิ่งที่เด็กกำลังเล่น
