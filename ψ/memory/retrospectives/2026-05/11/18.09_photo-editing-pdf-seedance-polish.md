## Honest Feedback

**Friction 1 — Gemini round-trips ยาวเกินไป**
รอบ Gemini photo editing ใช้เวลาหลายชั่วโมง ปัญหาหลักคือฉันให้ prompt ที่ขัดแย้งกัน (iris enlargement + face structure) โดยไม่รู้ว่ามันขัดแย้ง ถ้าฉันเข้าใจก่อนว่า generative AI สับสน geometry กับ expression ได้ — น่าจะ warn DewS ก่อนลอง ไม่ใช่แก้ปัญหาหลังจาก fail หลายรอบ

**Friction 2 — Edge CLI test ก่อนแนะนำ**
ฉันแนะนำ Edge CLI `--print-to-pdf-no-header` โดยไม่ได้ test จริงบน Windows ก่อน — แล้วปรากฏว่ามันไม่ reliable ต้องเปลี่ยนมา Playwright ทีหลัง เสียเวลา 2 รอบ ถ้าฉัน flag uncertainty ก่อน ("Edge CLI อาจ unreliable, Playwright น่าจะ safer") DewS จะตัดสินใจได้เร็วกว่า

**Friction 3 — Review ช้า vs real-time**
Seedance cheatsheet review ทำหลัง context เต็มแล้ว (คนละ session) เลยต้องโหลด + re-read ใหม่ ถ้า review ได้ real-time ระหว่างสร้างน่าจะ catch 唯一修改 ได้เร็วกว่า — แต่ก็เป็น tradeoff ของการ context window ที่ใหญ่

## Lessons Learned

1. **Context size = AI drift**: พื้นที่ทำงานใน generative AI เล็กลง → AI drift น้อยลง → ผลแม่นขึ้น ใช้ได้กับทุก multimodal AI
2. **DevTools Protocol > CLI flags**: สำหรับ browser automation แบบ precise ใช้ Playwright/Puppeteer โดยตรง อย่าหวัง CLI flags
3. **Guard conditions ใน event loops**: session state ต้องเช็คก่อน trigger quiet-period logic เสมอ
4. **Oracle Notes แยกจาก User content**: เอกสารที่ส่งต่อต้องมี section Oracle-only ที่ชัดเจน
