## Honest Feedback

**1. Prompt complexity escalation trap**: ทุกครั้งที่ผลผิด เราเพิ่มคำเข้า prompt แทนที่จะตัด นั่นขัดกับ guide ของเราเอง (section 19: ห้ามอัดก้อนเดียว ห้ามเกิน 150 คำ) ควรตั้ง rule กับตัวเองว่า "ถ้า feedback เกิน 2 รอบ → ตัด action ออกครึ่งหนึ่งก่อน"

**2. ไม่มี strategy สำรอง**: เมื่อ Seedance ทำ continuous action ไม่ได้ ควรเสนอ DewS ว่า "อาจต้องทำ 2 shots แล้ว cut ใน AE" ตั้งแต่รอบแรกที่เห็นปัญหา ไม่ใช่วน iterate ต่อ

**3. Uniform issue ควรจับได้ก่อน**: รู้ว่า Seedance ไม่รู้ context ไทย แต่ไม่ได้ใส่ uniform description ตั้งแต่ v1 ต้องรอให้เกิดปัญหาก่อน นี่คือ knowledge ที่ควร proactive ใส่เข้าไปตั้งแต่ต้นทุกครั้งที่มีตัวละครนักเรียนไทย

## Lessons Learned

- Thai student uniform ต้องระบุใน prompt เสมอเมื่อ gen live action ไทย: `girls: white blouse + dark navy pleated skirt (NOT trousers)`
- Seedance ทำ continuous motion FG→BG ไม่ถนัด — ถ้า action ต้องการ trajectory ข้ามระยะ ให้ split เป็น 2 shots แล้ว cut ใน AE ดีกว่า
- เมื่อ prompt ไม่ได้ผลหลัง 2 รอบ → ตัดออก อย่าเพิ่ม
