## Honest Feedback

**1. Screen sync ยังไม่ reliable**
Dreamina ทำ SCREEN SYNC ได้บ้างไม่ได้บ้าง — Doctor ได้ แต่ Chef ยังไม่ได้ ไม่มีวิธี guarantee ว่ามันจะ sync ได้ทุกครั้ง นี่คือ limitation จริงๆของ tool

**2. Dreamina hallucinate props ทุกครั้งที่ action คือ cooking**
ไม่ว่าจะเป็น stirring, pouring, chopping — ถ้าเกี่ยวกับอาหาร มัน gen วัตถุดิบหรืออุปกรณ์ขึ้นมาเสมอ ต้องหา action ที่ abstract กว่านี้

**3. ยังไม่ได้ update shots.md**
Shot structure เปลี่ยนหลายครั้ง (Shot 0 เพิ่ม, Shot 7 family ตัด, Shot 4 ตัด) แต่ shots.md ยังไม่ sync กับสิ่งที่เกิดขึ้นจริง

## Lessons Learned

1. **Dreamina hallucinate ทุก element ที่ไม่มี ref** — ต้อง lock ทุกอย่าง: uniform, props, background, ด้วย ref ที่ชัดเจน
2. **Screen sync เป็น optional feature ของ Dreamina** — ทำได้แต่ไม่ 100% — DewS ต้องเตรียม plan B สำหรับ AE composite
3. **กระทะ/props ติดมากับ cooking action** — ต้องหา body language ที่ abstract กว่าที่ไม่ trigger specific prop
