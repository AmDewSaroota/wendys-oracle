## Honest Feedback

**Friction 1 — Gray button: claim before verify อีกครั้ง**: บอก DewS ว่าปุ่ม gray แล้ว ทั้งที่ไม่ได้ test Tailwind CDN dynamic class limitation จริง. DewS ต้องรายงาน "ยังฟ้าอยู่" กลับมา. ควรรู้ว่า Tailwind CDN ไม่ generate dynamic classes ที่ไม่มีใน initial HTML — เป็น known limitation ที่ต้อง default ไป inline style สำหรับ dynamic color changes เสมอ.

**Friction 2 — ลบ simulation engine โดยไม่ trace callers ครบ**: ลบ ~300 บรรทัด simulation แล้วลืม verify ว่า `answerTvocQuestion(false)` ยังมี reference ถึง simulation flow ที่ถูกลบไปแล้ว. ทำให้ "ไม่เก็บ TVOC" กลับไปผิด step. ควร grep หา caller ทุกตัวก่อน submit เมื่อลบ subsystem ใหญ่.

**Friction 3 — DewS ยังไม่ได้ตรวจ 3 ไฟล์ที่ deploy**: `volunteer.html`, `guide-volunteer.html`, `index.html` ถูก deploy ไปแล้วแต่ DewS ยังไม่ได้ verify. ถ้า UI มีปัญหาจะเจอตอน workshop เท่านั้น. บันทึกไว้ใน focus.md แล้ว แต่ควรทำ self-check ก่อน deploy ด้วย — อย่างน้อย screenshot หรือ run through flow เองก่อน.

## Lessons Learned

- Tailwind CDN ไม่ generate dynamic classes → dynamic color changes ต้องใช้ inline style เสมอ
- เมื่อลบ subsystem → grep หา caller ทุกตัวก่อน submit
- "กดปุ่มบน mockup ได้จริง" ดีกว่า navigation button — workshop audience เข้าใจ flow ได้ตรงกว่า
- Quiet period check ที่ line 860 = UI guard เท่านั้น ไม่กระทบ server-side quota
