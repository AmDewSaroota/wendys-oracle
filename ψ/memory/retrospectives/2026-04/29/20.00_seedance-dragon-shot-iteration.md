## Honest Feedback

**1. เสียเครดิตเปล่าหลายรอบ** — ควรวิเคราะห์ root cause ก่อนแก้ prompt ตัวอย่างเช่น Shot 7 ปัญหาคือ ref image ล็อค glide pose ฉันรู้ตั้งแต่ต้นแต่ไม่ได้บอก DewS ตรงๆ ว่า "ต้องเปลี่ยน ref ก่อน text ถึงจะมีผล" ปล่อยให้ลอง text หลายรอบจนเสียเครดิตไป

**2. Prompt ยาวเกินไปหลายรอบ** — guide บอกชัดว่า 100-150 คำ max แต่หลายครั้ง prompt ที่ให้ไปเกิน 200 คำ ยิ่งเขียนเยอะ Seedance ยิ่งสับสน ควรตัดให้สั้นตั้งแต่แรก

**3. ไม่ได้แนะนำ post-production เร็วพอ** — รู้อยู่ว่า Seedance ทำ wing flapping กับ speed control ไม่ได้ดี แต่ยังพยายามแก้ด้วย prompt อีกหลายรอบ ควรบอก DewS ตั้งแต่รอบที่ 2-3 ว่า "เรื่องนี้ต้อง post-production"

## Lessons Learned

1. **Image ref ชนะ text เสมอ** — ถ้า ref มีท่า glide Seedance จะ glide ไม่ว่าจะเขียน text อย่างไร ต้องแก้ที่ ref ก่อน
2. **คำสั่งขัดแย้ง = Seedance เลือกเอง** — "กล้องนิ่ง + ร่างรุนแรง" Seedance ตีความว่าย้ายมังกร = กล้องหลุด
3. **คำอ่อน vs คำแรง** — "sways, rocks, rolls" = เบา; "THRASHES, JERKS, CRACKS" = แรง แต่ยังอาจทำให้กล้องหลุด
4. **Near-end ref ทำให้ชะลอ** — Seedance หยุด/ช้าลงเพื่อ transition ไปตำแหน่งใหม่
5. **Video ref ของผลลัพธ์ดีที่สุดจากรอบก่อน** คือทางแก้ที่ดีกว่าเขียน text ใหม่
