## Lessons Learned

1. **Audit trails > locks** — For admin input systems, "editable + visible history" beats "locked after first entry." Users make mistakes; locking creates worse problems than overwriting.
2. **Split text by context** — Long descriptive labels work in spacious areas, short labels work in table columns. Same concept, different verbosity. DewS's instinct to ask "ยาวไปป่ะ" was right.
3. **Always re-verify after context overflow** — Never trust the summary alone. Send an agent to read actual code before making edits. The 10 minutes spent verifying prevents 30 minutes of fixing wrong assumptions.
