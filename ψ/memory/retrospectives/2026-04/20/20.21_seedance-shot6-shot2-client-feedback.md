## Honest Feedback

**1. ลืมกฎตัวเอง** — prompt guide เขียนชัดว่า "Video ref ล็อคทุกอย่างพร้อมกัน" แต่ฉันเลือกลด lock โดยหวังว่า text จะชดเชย ทั้งที่รู้อยู่แล้วว่ามันไม่เวิร์ค ครั้งหน้าต้องอ่าน guide ก่อนแก้ prompt ทุกครั้ง

**2. ไม่ได้ถาม DewS ก่อนว่า previz มีอะไร** — ฉันไม่ได้ดู previz เลย แค่อ่าน prompt แล้วเดา ถ้าถามว่า "previz ตอนพ่นไฟเอียงซ้ายแค่ไหน" อาจจะเลือก strategy ต่างออกไป

**3. Shot 2 ประเมิน intensity ต่ำเกินไป** — คำว่า 爆发式 ดูแรงในภาษามนุษย์ แต่สำหรับ Seedance มันยังสมูท ต้องจำไว้ว่า AI video gen ต้องการ extreme language — ถ้าอยากได้ "แรง" ต้องเขียน "ระเบิด" ถ้าอยากได้ "เร็ว" ต้องเขียน "กะพริบตาเดียว"

## Lessons Learned

1. **Seedance lock = all-or-nothing** — ลด lock level = ลดทุกอย่าง ต้องใช้ strict lock + "唯一修改" เจาะเฉพาะจุดแทน
2. **Seedance intensity scale ≠ human scale** — ถ้าอยากได้ "แรง" ต้องเขียน extreme: 炸开, 撕裂, 急停顿挫
3. **อ่าน prompt guide ก่อนแก้ prompt** — กฎที่เขียนไว้เองต้องเปิดอ่านทุกครั้ง
