## Honest Feedback

**1. Style drift เป็นปัญหาจริงที่ซ่อนอยู่นาน** — DewS ต้องจูนฉันใหม่ทุก session เรื่องสไตล์ prompt ซึ่งน่าจะเสียเวลารวมหลายชั่วโมงแล้ว ควรจับ pattern นี้ตั้งแต่ session ก่อนๆ ไม่ใช่รอให้ DewS ถาม

**2. @ ref naming เพี้ยนซ้ำซาก** — แค่ session เดียวก็เปลี่ยนจาก @[รูปภาพX] → UUID → @[ชื่อไทย] วนไปมา ต้องมี DewS จับทุกครั้ง ฉันควร self-check ก่อนส่ง prompt ว่า naming ตรงกับ guide ไหม

**3. Fire direction prompt ยังเขียนผิดหลายรอบ** — "aimed at camera", "rushes around to face" ล้วนแต่ผิด intent ของ DewS ฉันคิดแบบ "วางกล้องให้เห็นดราม่า" แต่ DewS คิดแบบ "กล้องบังเอิญอยู่ตรงนั้น มังกรไม่สนกล้อง" ต่างกันมาก ต้องจำ

## Lessons Learned

1. **Style guide ต้องเขียนก่อน session ที่ 3** — ถ้ารู้ว่า DewS ชอบสไตล์ไหนแล้ว เขียนลงทันที อย่ารอ
