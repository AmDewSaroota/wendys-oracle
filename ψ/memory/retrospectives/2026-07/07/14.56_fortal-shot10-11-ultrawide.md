## Honest Feedback

**1. File ≠ Truth**: ฉันส่ง Shot 10 ultrawide โดยใช้ v7 จาก file เป็น base แล้วพบว่า v7 มี statue scene ที่ DewS ตัดออกนานแล้ว ถ้า DewS ไม่ส่ง prompt เก่ามาให้ดู ฉันคงไม่รู้ว่า file outdated ควร verify กับ DewS เสมอก่อน assume ว่า file = current

**2. Speed assumption**: ฉัน assume ว่า intensity ของ Shot 11 ต้องมาจากมังกรเร็ว จึงเพิ่ม "detonation" / "50-ton" language ซึ่งผิด DewS ต้องการมังกร predator ปกติ ไม่ต้องพิเศษ ความเข้าใจผิดนี้ทำให้เสีย iteration ไป 2 รอบ

**3. Camera fix ไม่แน่ใจ**: เพิ่ม chest-height axis lock แล้ว แต่ DewS ย้ายออกก่อนจะ test รอบใหม่ ยังไม่รู้ว่าจะได้ผลกับ Dreamina จริงหรือเปล่า — ความไม่แน่ใจนี้ค้างอยู่

## Lessons Learned

- ทหาร panic ที่ดีใน Dreamina ต้องไม่ใช่ "frozen" (นิ่งเหมือนหุ่น) และไม่ใช่ "runs immediately" (วิ่งเร็วเกินก่อนมีเหตุ) — ต้องเป็น agitation phase ก่อน: shifting weight, half-turning, confused — แล้วค่อย commit to sprint
- Intensity ของ shot ที่ทหารหนีมังกร ไม่ได้มาจากมังกรเร็ว แต่มาจากทหารช้าเกินไปที่จะรอด — predator ปกติแต่ prey ตัดสินใจสาย
- Source of truth = DewS's working prompt ไม่ใช่ file — ถาม/verify ก่อน assume
