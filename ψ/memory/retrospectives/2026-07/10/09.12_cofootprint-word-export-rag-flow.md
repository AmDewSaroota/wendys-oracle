## Key Fix: Word Export CSS

**ปัญหา**: exportWord เดิมส่ง CSS inline แค่ minimal (`h1,h2,h3`, `table`, `td,th`) — class ทั้งหมดของ proposal (`.feature-card`, `.compare-item`, `.rag-step`, `.section-title` ฯลฯ) ไม่มี definition → Word เห็นแค่ plain text เรียงๆ กัน

**แก้**: 
```js
var existingStyles = '';
document.querySelectorAll('style').forEach(function(s){ existingStyles += s.innerHTML; });
```
แล้วต่อด้วย `lightOverride` block ที่ force light theme ให้ทุก class ด้วย `!important` — ทำให้ layout ครบ แต่สีกลับมาอ่านได้ใน Word

## Lessons Learned

Word .doc (HTML MIME blob) ที่สร้างจาก JavaScript — ต้องแนบ CSS ทั้งหมดจาก DOM ไปด้วย (`document.querySelectorAll('style')`) ไม่ใช่แค่ hardcode inline styles — เพราะ class-based styling ทั้งหมดจะหายไปถ้าไม่ทำแบบนี้
