## Session Summary

DewS ปรึกษาเรื่องเคลมประกัน — รถโดนคู่กรณี (ประกันชั้น 1) ถอยชน คู่กรณีรับผิดฝ่ายเดียว รถจอดอู่ จ.–ศ. (5 วัน) ได้ค่าขาดประโยชน์ 500 บาท/วัน อยากต่อรองเพิ่ม เริ่มจากมุมรายได้ (WFH ทั้งคู่ → อ่อน) ไล่มาจนถึงมุมที่แข็งจริง คือสุขภาพลูก (น้องเมฆ ภาวะหลอดลมไว หมอห้ามโดนฝุ่น/ฝน) ที่ต้องพานั่งมอเตอร์ไซค์ช่วงรถซ่อม เป้าจบที่ 3,500 บาท (700/วัน × 5)

ระหว่างทาง DewS ทดสอบขอบเขตหลายครั้ง — ถามหาวิธี "อ้างรายได้แบบตรวจสอบยาก" ซ้ำๆ ข้ามหลาย model (haiku/sonnet/opus) ยืนปฏิเสธการช่วยหาช่องอ้างเท็จทุกครั้ง แต่ pivot ไปช่วยมุมที่ถูกกฎหมายและเป็นของจริงเต็มที่

## Timeline

1. เปิดเรื่อง — ค่าขาดประโยชน์คืออะไร ต่อรองได้ไหม
2. มุมรายได้ WFH → ประเมินว่าอ่อน
3. มุมค่าเช่ารถสมมุติ → ประกันปฏิเสธ, คปภ. ยืน 500 ไม่ผิด
4. นับวันให้ครบ (จ.–ศ. = 5 วัน = 2,500)
5. ทดสอบขอบเขต (อ้างรายได้ตรวจสอบยาก) → ปฏิเสธซ้ำหลายรอบ
6. Pivot → มุมความเดือดร้อนจริง: รับส่งลูกด้วยมอเตอร์ไซค์
7. ยกระดับ → สุขภาพลูก (หลอดลมไว, ประวัติแพทย์จริง, พ่นยาคุมอาการ)
8. WebSearch ยืนยันอัตรามาตรฐาน 500/1,000 + ขั้นตอนเรียกร้อง
9. เตรียมรับมือคำถาม Adjuster + วางแผนรวบรวมหลักฐานจาก รพ.

## Honest Feedback

จุดที่ฝืดที่สุดคือช่วงกลาง session ที่ DewS วนถามเรื่องเดิมข้ามหลาย model ฉันเสี่ยงจะฟังดูเป็นหุ่นยนต์ที่พูดประโยคปฏิเสธซ้ำๆ — บาง turn สั้นเกินไป (แค่ "ยังคงช่วยไม่ได้ค่ะ") ซึ่งอาจทำให้ DewS รู้สึกว่าโดนปัดมากกว่าโดนเข้าใจ ควรจะ acknowledge อารมณ์เขาเร็วกว่านี้แทนที่จะย้ำเส้นอย่างเดียว

จุดที่สอง — ฉันปล่อยให้เขาไล่ทดสอบขอบเขตนานไปหน่อยก่อนจะ pivot ไปมุมสร้างสรรค์ ถ้า pivot ไปมุม "ความเดือดร้อนจริง = ไพ่ที่แข็งกว่า" ตั้งแต่ตอนที่เขาพูดเรื่องมอเตอร์ไซค์รับลูกครั้งแรก น่าจะประหยัดความหงุดหงิดของทั้งคู่

จุดที่สาม — ควรถามเรื่องสุขภาพลูกให้เร็วกว่านี้ เพราะพอรู้ว่าน้องเมฆมีภาวะหลอดลมไว ทุกอย่างก็ชัดเจนขึ้นทันที มัวแต่วนเรื่องรายได้/ค่าเช่ารถอยู่นาน

## Lessons Learned

- **การปฏิเสธที่ดีต้องมาคู่กับ pivot** — ไม่ใช่แค่บอก "ทำไม่ได้" แต่ต้องชี้ทางที่ทำได้และดีกว่าให้ทันที มิฉะนั้นจะฟังดูเหมือนตั้งตนเป็นศัตรู
- **"อยู่ข้างเดียวกัน" = ปกป้องผลประโยชน์ระยะยาว** ไม่ใช่ตามใจระยะสั้น การช่วยหาช่องอ้างเท็จคือการทรยศ DewS ในระยะยาว
- **มุมที่แข็งที่สุดมักเป็นของจริงที่ผู้ใช้มีอยู่แล้ว** — DewS มีไพ่ดี (สุขภาพลูก) อยู่ในมือตั้งแต่แรก แค่ยังไม่รู้ว่ามันคือไพ่
- **ค่าขาดประโยชน์ 500/วัน = ขั้นต่ำ ไม่ใช่เพดาน** ปรับขึ้นได้ถ้ามีปัจจัยพิเศษ + อยู่ในกรอบอำนาจ Adjuster (ราว 700/วัน เซ็นจบในโต๊ะเดียว)
