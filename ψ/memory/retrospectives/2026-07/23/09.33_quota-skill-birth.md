1. **เดาข้อมูลบริษัทโดยไม่เช็ค memory** — ทั้งที่มี ndf-company-info อยู่แล้ว ควร grep memory ก่อนกรอกข้อมูล
   บริษัทลงเอกสารทางการทุกครั้ง นี่คือ friction ที่ทำให้ DewS เสียความเชื่อมั่น
2. **ถามเยอะเกินไป** — DewS พิมพ์ "ถามอะไรนักหนา" / "อย่าถามบ่อย ทำไปเลย" หลายรอบ ตอนงานเร่ง
   ควรเดาจาก context แล้วทำเลย ค่อยให้แก้ทีหลัง ดีกว่าหยุดถาม
3. **ใส่ Production Timeline ในใบเสนอราคา** — ผิดประเภทเอกสาร ใบเสนอราคา = รายการ+ราคาเท่านั้น
   เสียเวลาทำแล้วต้องรื้อ ควรรู้ convention เอกสารธุรกิจก่อน
4. **วนแก้ layout หลายรอบ** (หน้าตก/ไม่เต็มหน้า) เพราะไม่ได้ใช้ template ที่ proven ตั้งแต่แรก
