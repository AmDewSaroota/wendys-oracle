## Lessons Learned

1. **Autodesk license debug**: ต้องเช็ค nlm-server-info.json ใน `%ProgramData%\Autodesk\AdskLicensingService\` เสมอ — cached NLM server entry ที่มี version 0.0.0.0 คือต้นเหตุที่พบบ่อย
2. **Higgsfield @Image format**: refs แนบใน UI → tag เป็น @Image [n] อัตโนมัติ → ใช้ใน prompt text แทน @[ชื่อ]
3. **Autodesk Flex token**: rolling 24h จากเวลาเปิดครั้งแรก, 3ds Max = 6 tokens/day
