## Lessons Learned

1. **Higgsfield: 2-ref pattern** — ref 1 = CHARACTER (scales/color/expression), ref 2 = FRAMING ONLY (wing span layout). Label ชัดในทุก prompt
2. **Camera lock vs character move** — ถาม "กล้องเคลื่อนหรือตัวละคร?" ก่อนเขียน video prompt เสมอ ถ้าไม่แน่ใจ
3. **Higgsfield color drift** — ต้อง explicit lock ใน prompt แรก: NOT brown, NOT green, copy color grade from ref exactly
4. **Black bars จาก Higgsfield** — ถ้า output ratio ไม่ match content มันเพิ่ม bars เอง — ใช้ประโยชน์จากนี้ได้
