## Lessons Learned

- Chrome headless ไม่โหลด Google Fonts CDN → ต้อง embed base64 เสมอสำหรับ PDF generation
- Replace string ใน HTML ที่มี repeated structure ต้อง verify occurrence count ก่อน หรือ replace only first occurrence
- DewS: "ผิดก็แก้สิ" = อย่าถาม confirm เวลาชัดเจนแล้ว
