## Lessons Learned

- **AI image/video tool มีเพดานที่พรอมพ์แก้ไม่ได้** — Higgsfield outpaint = ย่อภาพเสมอ / Seedance = auto-exposure flicker บนฉากมืด. รู้จัก escalate ไป post-process (Flicker Free, AE manual, plugin) เร็วขึ้น.
- **"Far + เล็ก" ลบ identity ของฉาก** — เพราะเอกลักษณ์อยู่ที่ mid/foreground. ต้องหา differentiator ที่รอดระยะไกล (เพดานจังเกิ้ล vs ฟ้าเปิด).
- **Reference image = ติด layout มาด้วย** ไม่ใช่แค่สไตล์. ถ้าอยากได้แค่ลักษณะ ให้ describe เอง + สั่งชัดว่า "ref = appearance only, not positions".
- **คำที่ทำ video flicker**: pulse/twinkle/shimmer/glow/firefly. ตัดคำแสงทิ้ง เหลือ motion กายภาพ + เกราะ "lighting constant".
- **AE butterfly rig**: wing flap = keyframe spacing หรือ `Math.sin(time*freq*2π)*amp` (freq คุมเร็ว) / position smooth = `wiggle(f,a,1)` octaves=1 / glow = precomp+Glow หรือ Fill+blur / trail = Echo ก่อน Glow.
