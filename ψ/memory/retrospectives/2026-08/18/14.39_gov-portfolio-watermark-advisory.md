## Lessons Learned

- **ข้อความแจ้งลูกค้า = ฟังก์ชันของ (ผู้ส่ง, ผู้รับ, เจ้าของงาน)** ไม่ใช่แค่ถ้อยคำสวย ต้อง lock 3 ตัวแปรนี้ก่อนเขียน
- เมื่อผู้รับสารรู้เจ้าของงานอยู่แล้ว **พูดตรงดีกว่าเลี่ยง** — โปร่งใส = น่าเชื่อถือ
- แปลงความกังวลของลูกค้า ("กลัวผิดกฎ") เป็นภาษามืออาชีพ ("ระมัดระวัง/เคารพสิทธิ์") โดยคงเจตนาเดิม
- อ่าน scope ให้แคบก่อนเสนอ tool ใหญ่ — บางทีเขาแค่อยากได้ "คำ" ไม่ใช่ "ระบบ"
