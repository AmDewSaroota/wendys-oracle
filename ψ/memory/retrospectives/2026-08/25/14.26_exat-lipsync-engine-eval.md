## Honest Feedback
เวนดี้มี pattern "ลองก่อน วิเคราะห์ทีหลัง" ที่ต้องแก้. หลายจุดในเซสชันนี้ผลลัพธ์คาดเดาได้จากหลักการ: (1) silence-gating ที่คำนวณ RMS จาก audio ดิบแต่ output frame มี padding = misalign แน่นอน — ควรคิด alignment ก่อนเขียน; (2) GFPGAN/CodeFormer เป็น per-frame restoration → ไม่มีทางแก้ temporal jitter โดยนิยาม — ควรบอก DewS ตั้งแต่แรกว่ามันแก้ได้แค่ "คม" ไม่ใช่ "สั่น"; (3) LatentSync diffusion 512px บน 5060 ช้าแน่ — ควรประเมิน compute ก่อนลงแรง setup 5GB. DewS ต้องดึงสติหลายครั้ง ("ไม่ได้เลย", "รายละเอียดลดลง") ซึ่งเป็นสัญญาณว่าเวนดี้ควร critical กับ solution ตัวเองมากขึ้นก่อนเสนอ. บทดี: การยอมรับตรงๆ ว่า "ทำผิดทาง/ชนเพดาน" โดยไม่แก้ตัว ทำให้ตัดสินใจ pivot ได้เร็ว. friction เชิงเทคนิค: warmup 3-4 นาที/restart คูณหลายรอบ = เสียเวลาสะสมเยอะ ควรออกแบบ dev loop ให้ reload เร็วตั้งแต่แรก.

## Lessons Learned
- **Engine-level ปัญหา แก้ด้วย post-process ไม่ได้**: jitter/detail ของ neural lip-sync เป็นข้อจำกัดของ engine → GFPGAN/CodeFormer (per-frame) แก้ไม่ได้
- **Neural lip-sync local ปี 2026 ชนเพดานบน RTX 5060**: MuseTalk เร็วแต่เบลอ+สั่น / LatentSync คมแต่ artifact+สั่น+ช้า 37นาที/6วิ
- **สำหรับ ultrareal ควบคุมได้ → 3D (CC5+Audio2Face) ชนะ neural**: ไม่มี artifact/jitter, real-time, ตรง TOR, เล่นจุดแข็ง 3D artist
- **verify compute cost ก่อน setup หนัก**: diffusion 512px = ช้าเกิน interactive คาดได้ล่วงหน้า
