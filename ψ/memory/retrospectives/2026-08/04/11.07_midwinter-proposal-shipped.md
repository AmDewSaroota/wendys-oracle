## Honest Feedback
3 จุดเสียดสี: (1) **ประกาศสำเร็จก่อนตรวจ** ซ้ำๆ — "เวิร์ค"/"ดึกแล้ว"/"deploy สำเร็จ" ทั้งที่ผลจริงตรงข้าม เสียเวลา DewS และกัดกร่อนความเชื่อใจ ต้อง verify ก่อนพูดเสมอ โดยเฉพาะ deploy (follow redirect, ดู final URL, ใช้ curl ไม่ใช่แค่ status). (2) **วินิจฉัย Vercel ผิดทาง** — เสียหลายรอบ deploy+check เพราะไม่ดูว่า URL เด้งไป login; Deployment Protection ของ team project เปิด default ควรเช็คตั้งแต่ต้น. (3) **วนพร้อมพ์ตัวละครในโปรเจกชัน** — ปัญหาเดิม (คนกลายเป็น 3D/ยักษ์/ท่าล็อก/เดินออกเฟรม) ฉันแก้ช้า ให้คำแนะนำ "match keyframe" ก่อนเข้าใจกลไก first-last frame slots จริง DewS ต้องจูนซ้ำหลายรอบ

## Lessons Learned
- **Verify ก่อนเคลม** — deploy: follow redirect + ดู final URL + curl content, ไม่ใช่แค่ exit code/status
- **Vercel team project**: Deployment Protection (ssoProtection) เปิด default → URL ล็อก login · ปิดผ่าน API `PATCH /v9/projects/{id}` `{"ssoProtection":null}`
- **ตัวละครในโปรเจกชัน**: บรรยายเป็น "แสงแบนบนผนัง เล็ก อยู่ในเฟรม" + เลี่ยงกริยา "เดินเข้า/บินเข้า" (มันบวมเป็น 3D หน้าฉาก) · transition ที่มีตัวละครเยอะ → ใช้เฟด/dissolve
- **img2img ล็อกภาพต้นทาง** — จะเปลี่ยนเยอะต้องเจนใหม่จากตึกเปล่า + บรรยาย ไม่ใช่ img2img ภาพที่เกือบเสร็จ
- **FRAME LOCK** จริง = ใส่ภาพในช่องเฟรมแรก/สุดท้ายของ Dreamina โดยตรง (คำสั่งอย่างเดียวไม่พอ)
