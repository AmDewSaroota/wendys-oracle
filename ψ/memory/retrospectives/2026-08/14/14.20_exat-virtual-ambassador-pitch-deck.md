## Honest Feedback
1. **รื้อของเดิมโดยไม่จำเป็น** — สร้าง deck ใหม่ 2-3 รอบทั้งที่แก้ในไฟล์เดิมได้ ทำให้ DewS เสียเวลา/หงุดหงิด ควรถามตัวเองก่อนเสมอ "แก้ในที่เดิมได้ไหม" ก่อนสร้างใหม่
2. **สร้างสไลด์ล่วงหน้าเยอะเกินจังหวะ** — บางทีเพิ่ม voice/manual/criteria slides ก่อนที่ DewS จะเคลียร์ว่าต้องการ ทำให้ deck บวมเร็ว แล้วต้องมาตัด/ย้ายทีหลัง ควร propose ก่อน build เมื่อเป็น structural change
3. **assume "สามคน" ว่าตัดมณี** — DewS ถามกลับ "ทำไมต้องตัดมณี" ผมเดา 3 คนโดยไม่ถาม ควรถามเมื่อ requirement กำกวมแทนเดา

## Lessons Learned
- **แก้ในไฟล์เดิม > สร้างใหม่** เมื่อ user ลงแรงวางเนื้อหาแล้ว (Slides API replaceAllText/deleteObject/createImage แก้ text ได้โดยไม่แตะรูป)
- **อ่านเอกสารต้นทาง (TOR) ก่อนวางกลยุทธ์** — เด็คถูกให้คะแนนตามเกณฑ์ ไม่ใช่ความสวย
- **Seedance Thai TTS**: respell ชื่อ + คำทับศัพท์เป็นอังกฤษ · ไทย+EN ยาวในคลิปเดียวไม่ได้
- **เอกสารราชการ**: ห้ามอีโมจิหัวข้อย่อย · ห้ามจำแนกสีผิว/เชื้อชาติ · ชื่อองค์กรให้ตรงกันทั้งเล่ม
- **ซื่อสัตย์ในการเสนอราคา**: ยอมเพดาน ~75 (option B) ดีกว่าเสี่ยง 0 จากเคลม Real 3D ที่ไม่มีจริง
