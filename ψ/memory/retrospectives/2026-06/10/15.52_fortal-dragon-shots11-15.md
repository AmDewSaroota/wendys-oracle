## Key Learnings This Session

### 1. Phase Structure → ห้ามใช้เด็ดขาด
```
❌ Phase 1: ... Phase 2: ... Phase 3: ...
```
Dreamina หยุดระหว่าง phase ทุกครั้ง แทนด้วยบรรยาย action เดียวต่อเนื่องตลอด

### 2. Cut Into Mid-Action (Anti Ease-In)
```
We cut INTO this shot mid-action. Frame one: [action] already at maximum velocity.
No buildup. No acceleration. The camera arrives late — everything already underway.
```
Dreamina มักเริ่มช้าแล้วเร่ง — วิธีนี้บังคับให้เริ่มเต็มสปีดตั้งแต่เฟรมแรก

### 3. Time Allocation ใน 5s clip
บอก Dreamina ชัดว่าแต่ละส่วนใช้เวลาเท่าไหร่:
```
The dragon is visible for about 2 seconds of the clip. The remaining 3 seconds: camera continues alone.
```

### 4. Speed Calibration — 3 ระดับ
- **Glide** (ช้าเกิน): ภาษา gentle เกิน → แก้ด้วย `detonates / there and gone before the eye registers`
- **Warp** (เร็วเกิน): `under one second / cannot track` → แก้ด้วย `visible for 2 seconds, shape readable but smeared`
- **Bullet** (ถูก): `fast enough to catch briefly, slow enough to register as a creature`

### 5. Dorsal View (เห็นหลังมังกร) ขณะบินขึ้น
บินอิสระในอากาศ → Dreamina ให้ profile เสมอ
บังคับต้องบินขนานตามกำแพง:
```
Dragon ascends along the outer castle wall face — body nearly parallel to the stone surface, back facing outward toward camera. Dorsal view: spine ridge, back surface of wings, tail. NOT side profile.
```

### 6. Maya Playblast = Ref ห้ามใช้
Maya preview มีสี flat และ material ไม่ realistic → Dreamina ดูด color มาใส่ในวิดีโอ
ใช้เฉพาะ photorealistic refs เท่านั้น (Shot11_Ref.png, Shot13_ref5.png, Shot15_1st.png)

### 7. Dragon Speed Block (ใส่ทุก shot)
```
Dragon moves at full hunting velocity — wings don't glide, they hammer the air like pistons.
Body rigid, cutting through smoke. Not flying — a predator at full sprint.
```

### 8. Knight Panic Language
```
Not a warrior right now — a man in armored terror. Scrambling, lurching, stumbling —
body language of someone who has already accepted death. Not brave. Alive only by accident.
```

## Lessons Learned

1. **Dreamina narrative bias**: Default behavior = buildup → pause → action เพราะ training data → ต้อง explicit break pattern ด้วย "cut into mid-action" และ "the obstacle is already nothing"
2. **Maya ref = color contamination**: playblast colors ปนเปื้อนใน output — ใช้เฉพาะ photorealistic refs
3. **Phase structure = guaranteed pause**: ห้ามใช้ Phase 1/2/3 ใน Dreamina ไม่ว่ากรณีใด
4. **Speed calibration 3 ระดับ**: glide/bullet/warp มีภาษาที่แก้ต่างกัน — บันทึกแล้วใน skill.md
5. **Time allocation ใน clip**: บอก Dreamina ชัดว่าใช้เวลาเท่าไหร่กับแต่ละส่วน
