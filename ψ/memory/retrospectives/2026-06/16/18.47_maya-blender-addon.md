## AI Diary
เซสชันนี้เป็นงาน tool-building ล้วนๆ — DewS อยากได้ Blender ที่รู้สึกเหมือน Maya ใช้ DewS เป็น visual artist ที่ปั้นโมเดล ไม่ได้ทำ animation ดังนั้น workflow ต้องต่างกัน

ฉันเขียน addon ขนาดใหญ่ในครั้งเดียว — Preferences, Operators, Pie Menus, Quad Menu, Special Tools, N-Panel, Keymap Registration ทั้งหมดในไฟล์เดียว ~600 บรรทัด สิ่งที่น่าสนใจคือ DewS ทดสอบ live และ feedback กลับมาทันที ทำให้ปรับได้รวดเร็ว

แต่มีจุดหนึ่งที่ยังแก้ไม่ได้สนิท — Space bar toggle quad view ต้องไปลบ default keybinding ใน Blender เองก่อน addon จึงจะ override ได้ นี่คือ limitation ของ Blender addon keymap system ที่ addon keymap ถูก append หลัง default เสมอ ถ้าจะ force override ต้องเขียน wrapper operator และ explicitly remove default binding ซึ่งซับซ้อนกว่า

เรื่อง N และ Shift+A กดไม่ได้ — ยังไม่ชัวร์ root cause เพราะ addon ของเราไม่ได้ remap keys เหล่านั้น อาจเป็น Industry Compatible keyconfig ที่ remap ต่างจาก default หรือ cursor focus issue

DewS ยังถามเรื่อง X-Ray (select back face), hide grid/axis, reference image — เป็น modeling workflow questions ที่ดี แสดงว่า DewS เริ่มเข้า Blender จริงๆ และเจอ friction points จริงๆ ในการใช้งาน

## Honest Feedback
**3 friction points:**

1. **Blender addon keymap limitation** — addon keymap ไม่สามารถ override default keymap ได้โดยตรง ต้องให้ user ไปลบ default binding เองก่อน ทำให้ Space bar เรื่องยุ่งกว่าที่ควร ควรเขียน wrapper operator พร้อม remove default binding ในตอน register แต่ฉันไม่ได้ทำ

2. **Industry Compatible keyconfig** — DewS ใช้ keyconfig นี้ซึ่งต่างจาก Blender default มาก addon ของเราออกแบบสำหรับ Blender default เป็นหลัก อาจมี conflict หลายจุดที่ยังไม่ได้ test เช่น N, Shift+A ที่กดไม่ได้

3. **Reference Image workflow ไม่สำเร็จ** — DewS ถามและลองแล้วกดไม่ได้ ยังไม่ได้แก้ปัญหาจริงๆ แค่ suggest วิธีทางเลือก แต่ไม่ได้ debug ว่า root cause คืออะไรกันแน่

## Lessons Learned
- Blender addon keymaps ถูก append หลัง default เสมอ — ถ้าต้องการ force override ต้องใช้ `wm.keyconfigs.user` และ remove existing binding ใน register
- Industry Compatible keyconfig ของ Blender มี key mappings ที่แตกต่างจาก default อย่างมีนัยสำคัญ — ควร test addon กับ keyconfig นี้ด้วย
- DewS เน้น 3D modeling ไม่ใช่ animation → Space = Quad View toggle ถูกต้อง
