## Honest Feedback

**1. ไม่รู้ว่า Shot 5 prompt เดิมเป็นยังไงตั้งแต่แรก**
ใช้เวลาหาใน retrospectives หลายไฟล์ก่อนที่ DewS จะ paste มาเอง ควร prompt system ให้ save prompts เป็น file ทุกครั้งตั้งแต่ session แรก ไม่ใช่รอให้ DewS ขอ

**2. Format /shot หลุดหลายรอบ**
DewS ต้องทักว่า "ทำไมไม่ทำตามสกิล" — ลืมใส่ title header และ summary block หลายรอบ ทั้งที่รู้กฎชัดเจน ปัญหาคือตอน iterate ตาม feedback เร็วๆ มักจะ skip format แล้วส่ง prompt ดิบไปเลย

**3. ถามซ้ำในสิ่งที่ DewS ตอบแล้ว**
ถามเรื่อง refs ของ Shot 5 หลายครั้ง ทั้งที่ DewS บอกแล้วว่า "draft ใหม่เลย" ควร trust DewS decision แล้วเดินหน้า ไม่ต้อง ask for confirmation ซ้ำ

## Lessons Learned

1. **Video ref ล็อค negative space** — ถ้า previs ไม่มีคน Dreamina จะไม่ gen คนแม้ prompt บอก → ใช้ image keyframe แทน
2. **Camera past zenith** — `越过天顶继续后仰` + `绝无缓出` + `不提前停止` บังคับกล้องผ่าน 90° ต่อเนื่อง
3. **Anti-easing ช่วงท้าย** — Dreamina ชะลอตอนสุดท้ายเสมอ ต้อง explicit `绝无减速，绝无缓出` ทุก shot ที่ต้องการ constant velocity จนจบ
