## Lessons Learned

1. **Context ที่ไหลออกมาทีละชั้นต้องการ document ที่ evolve ได้** — HTML document ดีกว่า chat response ตรงที่แก้ไขได้ต่อเนื่อง
2. **Unity butterfly: forward axis คือ root cause ของปัญหา TOP view** — ต้องตรวจ mesh orientation ก่อน apply LookRotation เสมอ
3. **AE wiggle() seed ทำให้ layer ต่างกันอัตโนมัติ ใน Unity ต้องทำ explicit** — pattern นี้ apply กับทุก random behavior
