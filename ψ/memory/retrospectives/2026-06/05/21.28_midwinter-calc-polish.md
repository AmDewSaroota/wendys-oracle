## Honest Feedback

**1. Print layout วนซ้ำหลายรอบโดยไม่จำเป็น**
แก้ print CSS สามรอบ — `break-inside`, `margin vs padding`, `@page margin` — ถ้า audit ให้ครบก่อนรอบแรก น่าจะจบในรอบเดียว ปัญหาคือ test ได้ยาก ไม่มี live preview print

**2. Man-day table ตัวเลขไม่ sync กับ P object ตอนแรก**
เขียน reference table ก่อน แล้วค่อยเช็คกับ code — ทำให้ต้องแก้ storyboard.high และ anim.high ทีหลัง ควร derive ตัวเลข reference จาก P object โดยตรงหรืออย่างน้อย validate ก่อน commit

**3. Label text กระจายหลายที่**
"A / B / C" ปรากฏทั้งใน scope grid (ซึ่งควรเป็น A/B/C) และ table size card (ซึ่งตอนแรกก็ A/B/C) — ควร namespace ให้ชัดตั้งแต่ต้น เช่น `size-m/l/xl` vs `scope-a/b/c`

---

## Lessons Learned

1. `@page { margin }` ≠ `body { margin }` — page margin ใช้ที่ทุก page break, body margin ใช้แค่ outer edge ของ document
2. เวลา rename ตัวแปร JS ที่เป็น key ของ object ต้องเปลี่ยนทุกจุด: state init, DOM IDs, onclick handlers, calc() references
3. ราคา flat rate maintenance ที่ฟังดูสมเหตุสมผลสำหรับ fine dining: 40k–60k/ปี (~6–10 man-days)
