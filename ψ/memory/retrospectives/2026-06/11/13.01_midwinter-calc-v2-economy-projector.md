ViewSonic LS740HD เป็น addition ที่ดีมากค่ะ — lumens ใกล้เคียง Panasonic (5,000 vs 5,200) แต่ราคาต่างกันมหาศาล (฿45,900 vs ฿114,000) ถ้าลูกค้ามีงบจำกัด option นี้ตอบโจทย์ได้ดี สิ่งที่ต้องระวังคือ throw ratio และ ceiling mount compatibility ที่ยังต้องยืนยัน แต่สเปคเบื้องต้นผ่านค่ะ

## Honest Feedback

**1. ยังไม่ยืนยัน ViewSonic LS740HD ceiling mount compatibility**
เพิ่มเข้า calculator โดยยังไม่ได้ verify ว่า LS740HD รองรับการติดเพดานและฉายลงล่างได้จริงไหม สเปค throw ratio และ lens shift ยังไม่ได้เช็คละเอียด ควรเพิ่ม caveat ในไฟล์ว่า "ต้องยืนยัน ceiling mount compatibility ก่อน site visit" เหมือนกับ PT-VMZ51

**2. ราคา Economy markup อาจไม่สอดคล้อง**
ใช้ 21% markup เท่ากับ Standard แต่ไม่ได้ถามว่า NDF ต้องการ margin เท่ากันหรือเปล่า Economy projector อาจต้องการ margin ที่ต่างออกไป (อาจสูงกว่าเพราะเป็น "budget" tier ที่ต้องมี buffer สำหรับปัญหาที่อาจเกิดกับ lower-tier hardware)

**3. Web app control spec ยังคลุมเครือ**
บอกว่าทำได้ใน 1-2 วัน แต่ไม่ได้ระบุว่าใช้ tech stack อะไร feature อะไรบ้าง และ sync accuracy ได้แค่ไหน ถ้าลูกค้าถามลึกขึ้นอาจตอบไม่ครบ ควรทำ spec คร่าวๆ ไว้ก่อน

## Lessons Learned

- **ViewSonic LS740HD** เป็น viable Economy option — lumens ใกล้เคียง Panasonic แต่ราคาถูกกว่า 2.5 เท่า ต้องยืนยัน ceiling mount spec ก่อน
- **1 PC สำหรับ 10 outputs** แพงกว่าและเสี่ยงกว่า 10 mini PCs แยก — GPU multi-output setup ราคา ฿215k-335k vs ฿150k สำหรับ 10 mini PCs
- **Central control ผ่าน WiFi LAN + web app** = added value ที่ไม่มีค่าใช้จ่าย — รวมใน Scope C และใช้เป็น selling point ได้
- **ลูกค้าถามเรื่อง infra** = สัญญาณที่ดีว่าเขา serious กับโปรเจค
