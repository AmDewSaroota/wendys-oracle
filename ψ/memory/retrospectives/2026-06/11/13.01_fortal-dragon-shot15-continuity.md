## Honest Feedback

**1. เข้าใจภาพ Shot 16 ผิด — เสียรอบฟรี**
DewS ส่งภาพมาเพื่อบอก "รูหลังคาควรมีลักษณะแบบนี้" แต่ฉัน misread ว่า "กล้องมุมนี้โอเค" ทำให้ prompt v9 ให้กล้องอยู่ข้างใน ซึ่งผิดทันที วิธีป้องกัน: เมื่อ DewS ส่งภาพ ต้อง clarify ก่อนว่าภาพนี้เป็น reference ด้านไหน — camera angle, action, architecture, หรือ continuity ref

**2. Dreamina direction flip — ยังไม่มี silver bullet**
v13 explicit มากว่า "top-to-bottom, dragon FALLING, NOT ascending" แต่ Dreamina ยังทำช้าและ camera ผิด สิ่งที่ยังไม่ได้ลอง: ใช้ภาษาในแง่ของ gravity ("gravity pulls dragon DOWN toward the castle") หรือบอก relationship ระหว่าง sky/ground

**3. Gothic default ของ Dreamina ต้องต่อสู้ทุก shot ที่มี dome**
ทุกครั้งที่ใช้คำว่า "dome" หรือ "cathedral" Dreamina เพิ่ม Gothic elements เอง ต้องมี explicit negative list เสมอ: "NO flying buttresses, NO ribbed tracery, NO pointed arches, NO pinnacles, NO spires"

## Lessons Learned

1. **ภาพ ref จาก DewS = ต้องถามว่า ref ด้านไหน** ก่อน assume ว่า camera angle / action / continuity
2. **Dreamina + dome = Gothic default** → ต้องมี explicit negative list ทุกครั้ง
3. **Ref ที่แนบ = Dreamina lock camera angle ทันที** — ถ้าต้องการ action/silhouette จาก ref แต่ไม่ต้องการ camera angle → บรรยาย text อย่างเดียว ไม่แนบ ref นั้น
4. **Shot 16 frame จาก DewS = continuity reference สำหรับรูหลังคา** — ไม่ใช่ camera angle สำหรับ Shot 15
