## Lessons Learned

1. **Static ref → static output**: ถ้า starting frame ref มี element นิ่งอยู่ในรูป Dreamina จะ hold element นั้นนิ่งตลอด ต้อง remove จาก ref แล้วให้ text describe แทน
2. **"Pre-existing smoke" ต้องระบุ source ชัด**: ถ้าไม่ระบุว่า smoke มาจากไหน Dreamina render มันเป็น random background element
3. **Chase cam language**: "กล้องติดหลังมังกร" = camera follows directly behind ไม่ใช่ stationary
4. **ให้ prompt เต็มทุกครั้ง** — DewS ต้องการ copy-paste ได้เลย ไม่ใช่ fragment
