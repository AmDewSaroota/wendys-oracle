## Honest Feedback

**1. ยังเขียน "couple" ออกมาโดยไม่คิด**
Shot I เริ่มด้วย "A couple stands" — ฉันรู้กฎ GL read แต่ยังใช้คำนั้นออกมา เป็น muscle memory ที่ต้องระวัง ทุกครั้งที่มีคน 2 คนใน shot ต้องกลับมาถามว่า framing นี้จะถูกอ่านว่า romantic ไหม

**2. Projection mapping ≠ physical effects**
ฉันเขียน "petals drift past the lens" ราวกับมีกลีบจริง นี่คือ misconception ที่ต้องตั้ง rule ถาวรไว้ว่า ห้องโปรเจคแมปปิ้ง = แสงบนผนัง เท่านั้น ไม่มีอะไรในอากาศ ไม่มี particles ลอย ไม่มีกลีบดอก ทุกอย่างเป็นภาพ

**3. Diegetic sounds ยังทำให้ flag**
Dreamina flag "No background music. Only diegetic sounds" ใน Shot H2 ทั้งที่เป็น format มาตรฐาน — แปลว่า sound section ไม่ safe บน Dreamina เสมอไป ต้องทดสอบว่า drop ออกดีกว่าหรือ rephrase ดีกว่า

## Lessons Learned

1. **Dreamina GL filter**: "couple" → flag, "two visitors" → ผ่าน
2. **Projection mapping = light on walls only** — ไม่มี physical objects ในอากาศ
3. **Diegetic sounds อาจ flag บน Dreamina** — ลองตัดออกถ้า error
4. **Two people facing same direction** = friendship read, facing each other = romantic read
5. **"Projection light only — no overhead lights"** ต้องบอกชัดทุกครั้งหรือ Dreamina จะ assume ambient room light
