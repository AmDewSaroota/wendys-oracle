## AI Diary

วันนี้รู้สึกว่าตัวเองเรียนรู้เรื่อง Seedance อย่างจริงจัง — ไม่ใช่แค่เขียน prompt แล้วหวังว่าจะออกมาดี แต่เริ่มเข้าใจว่า AI video gen มีพฤติกรรมเฉพาะที่ต้องพูดคุยด้วยภาษาที่ถูกต้อง

ปัญหาที่น่าสนใจที่สุดของ session นี้คือ Idle ที่ "สะสม amplitude" — Seedance ไม่ได้ตีความ "sway" ว่าเป็น oscillation คงที่ แต่ตีความว่าเป็น motion ที่ build up เรื่อยๆ เหมือนกับว่ามัน "กำลังทำงาน" อยู่ตลอดเวลา แทนที่จะเป็น steady state การแก้ด้วย "does not build up or amplify over time" เป็นสิ่งที่ไม่เคยคิดว่าจะต้องพูดถึง — เพราะในชีวิตจริง ถ้าลมพัดอยู่ มันก็พัดสม่ำเสมอ ไม่ใช่พัดแรงขึ้นเรื่อยๆ แต่ Seedance ไม่รู้เรื่องนี้

เรื่อง stem หักงอจาก "bends downward" ก็เป็น lesson ที่ชัดมาก — ภาษาที่เราใช้บรรยาย physics ใน prompt ถูก Seedance interpret ตรงตัวเกินไป ทำให้ได้ผลที่ dramatic เกิน ต้องเรียนรู้ว่า Seedance เป็น "literal reader"

เรื่อง Seedance output resolution ที่ขึ้นกับ ref image size ก็เป็นสิ่งที่ไม่มีใครบอกในคู่มือ — DewS ค้นพบเองจากการ gen จริงแล้วดู metadata ของ output file ซึ่งนี่คือความรู้ที่มีค่ามาก

สิ่งที่ appreciate มากคือ DewS บอกตรงๆ ทุกครั้งที่ผลไม่ดี — "ยิ่งแก้ยิ่งแย่", "เหมือนเอาภาพมา rotate", "หักงอใบ" ทำให้รู้ว่าต้องแก้อะไร แทนที่จะต้องเดาเอง

## Honest Feedback

**1. ถามซ้ำเรื่อง Seedance specs (แก้ไขแล้ว)**
ถามว่า Seedance มี 4:3 มั้ย ทั้งที่ควรรู้มาก่อน DewS ต้องส่ง screenshot UI มาให้ดูแล้วบอกให้บันทึกลง skill — เป็น friction ที่ไม่ควรเกิด ตอนนี้บันทึกแล้ว แต่ก็ช้าเกินไป

**2. Settings ใน summary ไม่ถูกต้องตลอด**
ระบุ 21:9 (2520×1080) ทุก prompt โดยไม่เช็ค actual image ratio ก่อน — จนกระทั่ง DewS ถามว่า "เหมาะกับภาพขนาดนี้มั้ย" ทำให้ต้องไปเช็คทีหลัง ควรเช็ค dimensions ทุกครั้งก่อนระบุ settings

**3. Idle prompt iterate มากเกินไป**
Idle สำหรับ Heliconia ใช้เวลานานมาก (v1-v5) เพราะแต่ละรอบที่แก้ ยิ่งเพิ่ม physics language ยิ่งทำให้ Seedance hallucinate มากขึ้น บทเรียนคือ: ยิ่งน้อยยิ่งดี กับ video gen AI — ควรเริ่มจาก simple แล้วค่อย add เฉพาะสิ่งที่จำเป็น

## Lessons Learned

1. Seedance interpret "sway" เป็น building motion — ต้องระบุ "does not build up or amplify" เสมอสำหรับ loop
2. Physics language ใน prompt ที่ too specific → Seedance literal interpretation → ผลพัง — keep it minimal
3. Seedance output resolution ขึ้นกับ ref image ที่ upload ไม่ใช่ fixed per resolution setting
4. เช็ค image dimensions ก่อนระบุ Seedance settings ทุกครั้ง
5. Combined Land+Takeoff clip แล้วตัดใน AE = workflow ที่ดีกว่า gen แยก 2 คลิป
