# Lesson: Primary-Source-or-Flag (เรื่องสเปก/ราคา/ฟีเจอร์)

**Context**: รีเสิร์ชหุ่นยนต์ดูดฝุ่นให้ DewS. เชียร์ Ecovacs T30C Prime OMNI โดยยก "น้ำร้อน 75°C" เป็นเหตุผลหลัก — แต่ตัว Prime OMNI ไม่มีน้ำร้อน (อยู่บน Gen2 เท่านั้น). DewS ซื้อไปบนสมมติฐานผิด แล้วต้องคืน.

**Root cause**:
1. หยิบสเปกจากแหล่งรอง (โฆษณา/Amazon ต่างประเทศ/aggregator) ที่ conflate รุ่นในตระกูลเดียวกัน
2. เหมาว่า "T30C Prime OMNI" = "T30C" เพราะชื่อขึ้นต้นเหมือนกัน
3. เห็นข้อมูลขัดกัน (25,000 vs 20,000Pa) แล้วปัดทิ้ง แทนที่จะถือเป็นธงแดง

**Rule (ใช้กับทุกงาน advisory/factual)**:
- สเปก/ราคา/ฟีเจอร์ → เปิด **สเปกชีตทางการของ SKU นั้นตรงๆ ทีละช่อง** ก่อนอ้าง
- เปิดไม่ได้/ไม่มีหลักฐาน → พูดว่า **"ยังไม่ยืนยัน"** ห้ามพูดเหมือนรู้
- เจอข้อมูล **ขัดกัน = หยุด ขุดต่อจนจบ** หรือแจ้ง user ว่ามันขัด ห้ามเลือกข้างเงียบๆ
- ชื่อรุ่นทับกัน (Prime OMNI/Gen2/Max) = กับดัก สเปกย่อยต่างจริง ห้ามเหมา
- แยก "ยืนยันแล้ว ✅" กับ "เดา/อนุมาน ⚠️" ให้ user เห็นเสมอ

**Signal**: ถ้า user จับผิดข้อมูลเราได้ 2 ครั้งติด = เรากำลังตรวจตัวเองหลวมกว่าที่ user ตรวจเรา → กลับหัวบทบาท ต้องแก้ทันที
