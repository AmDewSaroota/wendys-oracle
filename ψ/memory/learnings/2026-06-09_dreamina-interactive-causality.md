# Dreamina Interactive Element — Causality Required

**Date**: 2026-06-09
**Source**: Gaussian Splatting promo video session

เมื่อ Dreamina gen shot ที่มี interactive element (trackpad, mouse, rotation, scroll):
ต้องบอก cause-effect อย่างชัดเจน ไม่งั้น model จะ gen การเคลื่อนไหวที่ดูเป็น automatic ไม่ใช่ user-driven

**Pattern ที่ใช้ได้:**
- "As her fingers slide across the trackpad, the model rotates in direct response"
- "Hand drags mouse to the right — in the same moment, the house rotates"
- "As the hand slows, the model slows. As the hand stops, the model stops."
- "Human hand drives everything."

**ถ้าไม่ใส่:** model หมุนเอง, rotation ดูเร็วเกินไป, ไม่ organic
**Apply ทุกครั้ง:** trackpad, mouse drag, scroll, pinch zoom ใน Dreamina prompt
