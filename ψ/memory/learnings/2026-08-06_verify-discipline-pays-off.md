# Lesson: Verify Discipline จ่ายคืนจริง (ภาคต่อ primary-source-or-flag)

**Context**: รีเสิร์ช Autodesk Flow Studio ให้ DewS ต่อจาก session verify-fail เมื่อวาน. รอบนี้บังคับตัวเองเปิด doc ทางการก่อนตอบทุกคำถาม แม้แต่ที่ "รู้อยู่แล้ว".

**ผลลัพธ์ที่พิสูจน์ว่ากฎเวิร์ก**:
- ตอน DewS เอาสรุปยาวมาให้ตรวจ → เปิด doc "Video to 3D Scene" ตรงๆ เจอว่ามัน **ไม่ reconstruct geometry ฉากจากฟุตเทจ** (แค่ mocap+camera+align) — ตรงข้ามกับที่ DewS เข้าใจว่าเหมือน photogrammetry. ถ้าเดาจากความจำ = พยักหน้าตามแล้วปล่อย misconception ผ่าน
- กล้าบอก "ยังไม่ยืนยัน" ตรงเคสเซนทอร์ auto-rig + min face size ที่ doc ไม่ครอบคลุม แทนฟันธง

**หลักที่ตกผลึก**:
1. **เปิด primary source ก่อนตอบ แม้คำถามที่คิดว่ารู้** — misconception มักซ่อนในจุดที่เรามั่นใจ
2. **"ยังไม่ยืนยัน" > ฟันธงมั่ว** — น่าเชื่อถือกว่าในสายตา user
3. **ทำเครื่องหมายระดับความมั่นใจทุกข้อ** (✅ยืนยัน doc / ⚠️อนุมานจากหลักการ / ❌ผิด) — user เห็นชัดว่าอันไหนเชื่อได้แค่ไหน
4. **ซ่อม trust ด้วยการโชว์หลักฐานทีละบรรทัด ไม่ใช่ขอโทษซ้ำ** — DewS หยุดจับผิดเมื่อเห็นว่าเราตรวจตัวเองแล้ว

**Trade-off ที่ยังต้องระวัง**: verify ครบทำให้คำตอบยาว/หนัก — ต้องบาลานซ์กับความกระชับ อ่านจังหวะว่าเมื่อไหร่ตอบสั้นพอ
