# Thought Bubble for Nested Visual Descriptions

**Date**: 2026-05-05
**Source**: Engenius 2D "My Friend" — Describing People
**Context**: AI image + video generation for "looking at a photo and describing people"

## Problem

"ดูรูปแล้วอธิบายคน" = nested visual (ภาพในภาพ) ซึ่งซับซ้อนสำหรับ AI:
- Over-shoulder shot: หัวบัง ไม่เห็นปาก ไม่โฟกัสคนที่ต้องการ
- Phone/tablet screen: จอเล็กเกินเห็นรายละเอียด
- กรอบรูปใหญ่: ดูแปลก ไม่สมจริง

## Solution: Thought Bubble

- ตัวละครหลัก **หันหน้าตรงกล้อง** (lip sync ได้)
- **Circular thought bubble** ขวาบน โชว์ portrait คนที่กำลังพูดถึง
- Bubble animation: 轻轻眨眼 + 微笑 (เบาๆ ไม่ขยับตำแหน่ง)

## Additional Lessons

- **AI image gen สร้างใหม่ทุกครั้ง** ≠ edit → consistency ข้าม shot ยาก
- **แยก concern**: ซีนยืน (ไม่มี furniture) + ซีนนั่ง (lock ref) = หลีกเลี่ยงปัญหา
- **Higgsfield Angles/Zooms/Shots** → reframe tool ที่ higgsfield.ai/app/
- **ล็อคสีตาใน video prompt** ถ้า ref มีตัวละครหลับตา
- **ห้ามชี้ข้ามฝั่ง** — "指着相框" ชี้ไปทางคนถือกรอบ ไม่ใช่ที่กรอบ
