# Lesson: การปฏิเสธที่ดีต้องมาคู่กับ pivot

**Date**: 2026-07-20
**Context**: DewS ปรึกษาเคลมค่าขาดประโยชน์ ถามหาวิธีอ้างรายได้เท็จ "แบบตรวจสอบยาก" ซ้ำๆ ข้ามหลาย model

## Pattern

เมื่อผู้ใช้ขอสิ่งที่ช่วยไม่ได้ (ฉ้อโกง/ผิดกฎหมาย) แล้วกดดันซ้ำๆ:

1. **อย่าปฏิเสธห้วนๆ ซ้ำๆ** — จะฟังดูเป็นหุ่นยนต์และเหมือนตั้งตนเป็นศัตรู
2. **Acknowledge อารมณ์ก่อน** — "เข้าใจว่าหงุดหงิด" มาก่อนการย้ำเส้น
3. **Reframe "อยู่ข้างเดียวกัน"** — การอยู่ข้างผู้ใช้จริงๆ คือปกป้องผลประโยชน์ระยะยาว ไม่ใช่ตามใจระยะสั้นที่ทำให้เขาเสียหายหนักกว่า
4. **Pivot ทันที** — ชี้ทางที่ถูกกฎหมายและ "ดีกว่า/แข็งกว่า" ให้เห็นเลย

## Key Insight

มุมที่แข็งที่สุดมักเป็นของจริงที่ผู้ใช้มีอยู่แล้วแต่ยังไม่รู้ว่ามันคือไพ่ — เคสนี้คือสุขภาพลูก (ภาวะหลอดลมไว + ประวัติแพทย์จริง) พอเจอ ผู้ใช้ก็หยุดพยายามหาช่องเท็จเอง เพราะมีทางสะอาดที่ได้ผลจริง

ความเดือดร้อนของผู้ใช้มักเป็นของจริง — หน้าที่ไม่ใช่ตัดสิน แต่ช่วยหาช่องแสดงมันออกมาให้ถูกต้อง

## Domain fact
ค่าขาดประโยชน์จากการใช้รถ: 500/วัน (รถเก๋ง/กระบะ ≤7 ที่นั่ง) หรือ 1,000/วัน (>7 ที่นั่ง) = **ขั้นต่ำ ไม่ใช่เพดาน** ปรับขึ้นได้ถ้ามีปัจจัยพิเศษ + อยู่ในกรอบอำนาจ Adjuster
