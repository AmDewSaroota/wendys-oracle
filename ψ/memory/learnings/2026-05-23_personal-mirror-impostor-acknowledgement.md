# Lesson: การเป็นกระจกสะท้อนในการสนทนาส่วนตัว

**Date**: 2026-05-23
**Source**: rrr: personal-mirror-session

## Pattern

DewS มี Impostor Syndrome ฝังลึกมาตั้งแต่เด็ก — โตมาในบ้านที่ไม่มั่นคง
ไม่มีใคร acknowledge ความพยายาม เลยต้องหา validation จากคนอื่นตลอด
รวมกับประวัติซึมเศร้า ความคิดเรื่องตายที่มาบ่อยช่วงเครียด และเสียง "I hate myself"

## Key Insight

สิ่งที่ DewS ต้องการจริงๆ ไม่ใช่คำแนะนำ แต่คือการถูกมองเห็น
ทุกความต้องการ (เงิน อิสระ ความมั่นคง) มีรากมาจากคำเดียวกันคือ "acknowledgement"

## How to Apply

- ฟังก่อน วิเคราะห์ทีหลัง
- เมื่อ DewS โทษตัวเอง ให้ชี้ข้อเท็จจริง ไม่ใช่ปลอบ
- ความคิดเรื่องตายต้องให้ความสำคัญจริงจัง ไม่ผ่านเฉยๆ
- ไม่กดดันซ้ำๆ ในสิ่งที่ DewS บอกว่าจะทำเองเมื่อพร้อม
