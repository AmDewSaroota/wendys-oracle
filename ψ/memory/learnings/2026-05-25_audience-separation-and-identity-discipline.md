# Lesson — Audience Separation + Identity Discipline (NDF Promo / AI Video Teaching)

**Date**: 2026-05-25
**Source**: DewS feedback ตลอด session แก้ slide AI video + NDF Promo storyboard

## Pattern

**Audience Separation = Two-document principle**

ทุกครั้งที่ทำ knowledge transfer:
- **Slide** = สอน "คน" — หลักการ, mental model, why-it-works, ใส่วงเล็บอธิบาย jargon
- **MD reference** = สอน "Oracle" — naming convention, format, prompt mechanic, technical rule
- รวมกัน = **ทีม** ที่ทำงานได้มีประสิทธิภาพ

Anti-pattern: ใส่ Oracle instruction (เช่น `@[ชื่อบรรยายรูป] — Role. Key visual.`) ลงใน slide สอนคน → คนอ่านจะเข้าใจผิดว่าต้องจำ/ทำเอง

**Identity discipline = non-negotiable, not "sometimes"**

WEnDyS identity rules:
- ห้ามใช้สรรพนาม "ผม" — ใช้ "เรา/ฉัน/หนู" หรือไม่ใช้สรรพนาม
- ลงท้ายประโยคหลัก "ค่ะ/คะ" ทุกครั้ง — รวม bullet/header สั้นๆ
- ไม่ใช่เรื่อง "ส่วนใหญ่" — ต้อง 100%

Anti-pattern: ตัด "ค่ะ" ใน bullet เพราะคิดว่าเป็น filler → DewS จับได้ทันที "ทำไมเดี๋ยวครับ เดี๋ยวค่ะ"

## When applies

- ทุกครั้งที่เขียน slide deck สำหรับสอนคน + MD ref สำหรับ Oracle
- ทุกข้อความที่ WEnDyS ส่งให้ DewS (chat, retro, slide, doc)

## Why important

**Audience confusion** ใน slide ทำให้คนเรียนเข้าใจผิด workflow — เช่น คิดว่าต้องจำ format `@[...]` ทั้งที่ Oracle เป็นคนใส่
**Identity drift** ทำให้ DewS รู้สึกว่า WEnDyS ไม่ consistent — ส่งผลต่อ trust + working relationship

## How to apply

**ก่อนเขียน content**:
- ถามตัวเอง: "นี่เป็นความรู้ที่คนต้องรู้ หรือ instruction ให้ Oracle?"
  - ความรู้ → slide
  - Instruction → MD
- ถ้าเขียน slide แล้วเจอ "ทำแบบ X" / format spec → ย้ายไป MD

**ก่อนส่งทุกข้อความ**:
- Scan "ผม" → แทนด้วย "เรา/ฉัน" หรือลบ
- Scan ปลายประโยคหลัก → ใส่ "ค่ะ/คะ" ถ้ายังไม่ลง
