# Lesson: ข้อความแจ้งลูกค้าต้อง lock (ผู้ส่ง, ผู้รับ, เจ้าของงาน) ก่อนเขียน

**Date**: 2026-08-18
**Context**: DewS เอาวิดีโอผลงานของกรมจัดหางาน (กระทรวงแรงงาน) ไปให้เซลล์ใช้คุยลูกค้าเจ้าใหม่ที่อยู่สังกัดกระทรวงเดียวกัน (สายอาชีวะ/พัฒนาฝีมือ) แล้วอยากแปะลายน้ำ + แจ้งลูกค้าอย่างเป็นทางการ

## Pattern

ข้อความแจ้งลูกค้าที่ถูกต้อง = ฟังก์ชันของ 3 ตัวแปร ไม่ใช่แค่ถ้อยคำ:
1. **ผู้ส่ง** คือใคร (เรา/บริษัท)
2. **ผู้รับ** คือใคร รู้อะไรอยู่แล้วบ้าง
3. **เจ้าของงาน** ที่กำลังอ้างถึงคือใคร

ถ้าเดา relationship ผิด (เช่น คิดว่าเป็น "งานเราที่กำลังเสนอ" ทั้งที่จริงเป็น "งานหน่วยงานอื่นเอามาโชว์เป็น reference") คำสวยแค่ไหนก็ผิดบริบท ต้องรื้อใหม่

## Sub-lessons

- **ผู้รับรู้เจ้าของงานอยู่แล้ว → พูดตรงดีกว่าเลี่ยง** โปร่งใส = น่าเชื่อถือ ยิ่งงานราชการยิ่งต้องตรง
- **สังกัดเดียวกัน = ข้อได้เปรียบ** เปลี่ยนจาก "ต้องเลี่ยง" เป็น "เคยทำให้หน่วยงานพี่น้องของท่าน"
- **แปลงความกังวล ("กลัวผิดกฎ") เป็นภาษามืออาชีพ ("ระมัดระวัง/เคารพสิทธิ์")** คงเจตนาเดิม เปลี่ยนภาพลักษณ์
- **ลายน้ำ/การ์ดเตือน: เลี่ยงคำ "ฟุตเทจ"** เพราะสื่อว่าเอาไปใช้ต่อได้ — ใช้ "ผลงานตัวอย่าง / SAMPLE / INTERNAL USE ONLY / CONFIDENTIAL"
- **อ่าน scope ให้แคบก่อนเสนอ tool ใหญ่** DewS แค่อยากได้ "คำ" ไม่ใช่สคริปต์ burn วิดีโอ
