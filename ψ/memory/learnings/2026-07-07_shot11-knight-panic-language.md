# Knight Panic Language for Dreamina

**Date**: 2026-07-07
**Project**: Fortal Dragon — Shot 11

## Pattern

ทหารที่หนีมังกรใน Dreamina ต้องผ่าน 2 phase:

1. **Agitation phase** (ก่อนวิ่ง): shifting weight, half-turning then stopping, hands up then dropping, head snapping left/right — กระวนกระวาย สับสน ยังไม่รู้จะทำอะไร ไม่ใช่ frozen นิ่ง ไม่ใช่วิ่งทันที
2. **Sprint phase**: commit to run → full desperate sprint, stumbling, armor clanking — ไม่ใช่ jog

## Key Insight

Intensity ไม่ได้มาจากมังกรเร็ว — มาจาก **ทหารตัดสินใจช้าเกินจะรอด**
มังกร predator ปกติ ไม่ต้องพิเศษ — "เดินเร็วๆก็ยังทัน แต่ทหาร jog"

## Avoid

- "frozen" / "paralyzed" → Dreamina ทำหุ่นนิ่ง
- "runs immediately" → ไม่มี dramatic tension
- Speed block แบบ "detonation" ให้มังกร → ไม่ใช่แหล่ง intensity จริง
