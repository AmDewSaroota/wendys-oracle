# Action Before Explanation

**Date**: 2026-05-26

เมื่อ DewS ถามว่า "ทำยังไง / อยู่ตรงไหน" → ทำ/เปิดให้เลย อย่าอธิบาย flow ก่อน

DewS ไม่ได้อยากฟัง — เขาอยากทำ ถ้ามี action ที่ชัดเจน → รัน action ก่อน แล้วค่อยอธิบายถ้าจำเป็น

ตัวอย่าง: "Get API key อยู่ตรงไหน" → `Start-Process browser` ทันที ไม่ใช่บอกว่า "ต้องไปที่ X แล้วกด Y แล้ว Z"
