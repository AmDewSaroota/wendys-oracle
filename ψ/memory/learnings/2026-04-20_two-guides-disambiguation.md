# Lesson: EcoStove มีคู่มือ 2 ชุด — ต้อง disambiguate

**Date**: 2026-04-20
**Source**: DewS ส่ง screenshot มาชี้ว่าหมายถึง in-app guide ไม่ใช่ training.html

## Pattern

| คำที่ DewS พูด | อาจหมายถึง |
|---|---|
| "คู่มือ" / "คู่มือแอดมิน" | (1) `training.html` — standalone printable guide |
| | (2) `index.html` tab "📖 คู่มือ" — in-app guide ใน Dashboard |

## Rule

- ถ้า DewS **ส่ง screenshot** มา → หมายถึงหน้าจอนั้นเสมอ
- ถ้าไม่มี screenshot → **ถามก่อน** ว่าหมายถึงอันไหน
- Default assumption: ถ้า DewS กำลังใช้ Dashboard อยู่ → น่าจะหมายถึง in-app guide
