# ตัวเลขที่ผิดปกติจาก context ต้องตรวจก่อนใส่

**Date**: 2026-07-06
**Source**: rrr: dreamina-tracker

เมื่อ user บอกตัวเลขที่แตกต่างจาก context มากผิดปกติ (เช่น 37.2 ท่ามกลาง account อื่นที่มีหลักพัน-หมื่น) ให้ตรวจสอบ unit ก่อนเสมอ อาจเป็น K (×1000) ที่ user ลืมระบุ

**Pattern**: sanity check ตัวเลขกับ context รอบข้าง → ถ้าแปลกผิดปกติให้ถามหน่วยก่อน
