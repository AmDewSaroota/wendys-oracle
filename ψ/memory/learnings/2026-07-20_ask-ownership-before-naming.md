ถามว่าโปรเจคเป็น in-house หรือ commission ก่อนตั้งชื่อเสมอ

**Why:** session นี้เสนอชื่อ NDF-centric ทั้งหมด แต่จริงๆ เป็นงานที่ลูกค้าจ้าง NDF ทำ ทำให้ชื่อที่เสนอ miss context ทั้งหมด

**How to apply:** เมื่อ user ถามให้ตั้งชื่อโปรเจค ให้ถามก่อนว่า "เป็นของ NDF เองหรือลูกค้าจ้างทำ?" — ถ้า commission ควรอ้างอิงชื่อลูกค้าเป็นหลัก
