ใน prompt สำหรับ immersive art space: **ห้องและ projection คือ hero** — คนเป็นแค่ proof ว่าห้องมีชีวิต

**Why:** ถ้า prompt โฟกัสที่ action ของคน → AI generate ออกมาเหมือนจัดฉาก, staged, theatrical
ถ้า prompt โฟกัสที่ห้อง/บรรยากาศ → คนในภาพดูเป็นธรรมชาติ เพราะ AI ไม่ได้ "ออกแบบ" พวกเขา

**How to apply:** เริ่ม prompt ด้วย venue/space/projection ก่อนเสมอ — คนมาทีหลัง และอธิบายแค่ว่า "อยู่ที่ไหน ทำอะไรอยู่คร่าวๆ" ไม่ใช่ choreograph ทุก action
