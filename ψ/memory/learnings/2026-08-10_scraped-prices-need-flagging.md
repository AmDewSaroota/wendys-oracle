# Lesson: ราคาจาก web scrape ต้อง flag ความไม่แน่นอน

**Date**: 2026-08-10
**Context**: รีเสิร์จราคาแอร์ Midea Chione ให้ DewS

## สิ่งที่เกิดขึ้น

WebFetch ดึงราคา Chione 9360 จาก HomePro มาได้ ฿6,984 (จากป้าย ฿19,990 ลด 61%) — ฉันบอกต่อว่า "ราคาตลาด ~7,000". พอ DewS ส่ง screenshot ตะกร้าจริงมา ราคาคือ ฿11,490 → net ฿9,399. ตัวเลข scrape คลาดไปเกือบ 40%.

## บทเรียน

1. **ราคาจาก WebFetch/WebSearch อาจเป็นโปรเก่า, cache, หรือ SKU คนละตัว** — ไม่ใช่ ground truth
2. เวลาอ้างราคาจาก scrape ต้องพูดชัดว่า "ยึดตะกร้าจริง/ราคาหน้าร้านเป็นหลัก ตัวเลขนี้อ้างอิงคร่าวๆ"
3. **ป้ายราคา MSRP ที่ลดเยอะๆ (ลด 60%+) มักเป็นราคาตั้งเว่อร์** — เตือนผู้ใช้อย่ายึด
4. Screenshot/ภาพเอกสารจริงจากผู้ใช้ = แม่นกว่า scrape เสมอ ให้ reconcile ทันทีเมื่อได้มา
