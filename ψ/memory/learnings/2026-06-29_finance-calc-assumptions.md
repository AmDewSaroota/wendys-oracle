# Financial Calculation — Always State Assumptions First

เมื่อคำนวณการเงินระยะยาว ต้องแจ้ง assumption ก่อนเริ่ม:
- MRR / อัตราดอกเบี้ยคงที่หรือไม่?
- รวมค่าธรรมเนียม refi หรือไม่?
- สมมติอะไรเกี่ยวกับโปรโมชั่นอนาคต?
