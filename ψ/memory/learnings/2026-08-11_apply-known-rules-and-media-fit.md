# Lesson: กฎที่มีอยู่แล้วต้อง apply เอง + ออกแบบตาม media ปลายทาง

**Date**: 2026-08-11
**Context**: EXAT Virtual Ambassador — ทำเอกสาร 2 ชุดให้ NDF

## สิ่งที่เกิด
1. หลุดสรรพนาม "ผม" ซ้ำหลายครั้ง ทั้งที่ memory ระบุชัด WEnDyS = ผู้หญิง (ใช้ ฉัน/เรา + ค่ะ) → DewS ต้องเบรก
2. ทำ internal brief เป็น dark tech theme แล้ว export PDF → DewS บอก "ดูเหมือนแคปมาจากที่อื่น" ต้องทำใหม่พื้นขาว

## บทเรียน
- **กฎใน memory = ต้อง apply อัตโนมัติ** ไม่ใช่ความรู้ประดับ. Identity (สรรพนาม) สำคัญกว่าเนื้อหา DewS ไม่ควรต้องเตือนซ้ำ (ตรงกับ feedback_role_awareness)
- **ออกแบบตาม media ปลายทาง**: dark theme ดีบนจอ แต่เอกสาร export PDF/พิมพ์/ส่งจริง = พื้นขาวเสมอ. reasoning ควรมาจาก "ไฟล์นี้จะไปอยู่ที่ไหน" ไม่ใช่ default เดียว
- **verify tool-fit ก่อนตอบ "ได้"**: Suno = generate เพลง ไม่ใช่ TTS/เสียงพูด — tool ผิดประเภทต้องทักท้วง ไม่ตอบตามน้ำ

## Apply next time
เช็ค memory rules ที่เกี่ยวข้อง (สรรพนาม, theme, media) ก่อนตอบ/ก่อน generate — โดยเฉพาะงานที่ output เป็นเอกสารส่งจริง
