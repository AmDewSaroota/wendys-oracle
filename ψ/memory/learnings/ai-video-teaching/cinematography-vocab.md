# Cinematography Vocabulary for AI Video Prompting

**Purpose**: Reference glossary สำหรับเขียน prompt AI video (Seedance/Sora/Runway/Kling) — เลือกคำที่ "model เข้าใจ" + "ผลออกมาเหมือนหนัง"
**For**: WEnDyS, Oh's Oracle, Oracle อื่นๆ ที่ทำงานเขียน prompt video
**Last research**: 2026-05-06 (DewS request)
**Source**: Web research + dragon project experience

---

## Why This Glossary Exists

AI video models (Seedance, Sora, Runway Gen-4, Kling) **เทรนกับวิดีโอจริง / หนัง** — ไม่ใช่ game engine output

→ พูด **ภาษา cinematography** = ผลออกมา **เหมือนหนัง**
→ พูด **ภาษา 3D engine** (parallax, PBR, FOV, etc.) = ผลออกมา **แข็ง CG**

DewS เรียนรู้เองจากประสบการณ์ดูคนอื่นทำพลาด → ผลกระดิก ไม่สมูท

## 📷 Cameras & Brands (Camera Look)

| Term | คำอธิบาย | เมื่อไหร่ใช้ |
|------|---------|--------------|
| **ARRI ALEXA** | กล้องดิจิทัลที่ Hollywood ใช้ 80%+ (Dune, Oppenheimer, Joker) | Premium cinematic look |
| **ARRI tone / ARRI color** | ลายเซ็นสี ARRI — warm skin, teal shadows, golden highlights, soft roll-off | ทุกครั้งที่อยาก "ดูเป็นหนัง" |
| **ARRI color science** | คำเดียวกับข้างบน, formal กว่า | ใช้แทน "ARRI tone" ก็ได้ |
| **Kodak film stock** | ฟิล์ม Kodak — สีอบอุ่น contrast แรง warm bias | หนัง vintage / period drama |
| **Fuji film stock** | ฟิล์ม Fuji — สี pastel นุ่ม pastel cooler | mood นุ่มนวล / อินดี้ |
| **Shot on 35mm / Shot on 70mm** | ระบุรูปแบบฟิล์ม → cinematic feel | ขอ feeling แบบฟิล์ม |
| **IMAX format** | aspect ratio ใหญ่ + grain ละเอียด | epic scale |

## 🔭 Lens & Look (Lens Vocabulary)

| Term | คำอธิบาย |
|------|---------|
| **Anamorphic lens** | เลนส์หนัง widescreen, bokeh ขอบยืด, lens flare แนวนอน |
| **Cooke S4 / Cooke lens** | เลนส์ฟิล์ม vintage, ผิวนุ่ม "Cooke look" |
| **Zeiss prime / Master Prime** | เลนส์คมเป็น crystal sharp |
| **Wide-angle lens (24mm / 35mm)** | มุมกว้าง drama, distortion ขอบ |
| **Standard prime (50mm)** | มุมสายตามนุษย์ natural |
| **Portrait lens (85mm prime)** | บีบ background, bokeh ครีมมี่, ภาพถ่ายคน |
| **Telephoto (135mm / 200mm)** | บีบ space, compression effect |
| **Macro lens** | ใกล้สุด รายละเอียดเล็กๆ |
| **Tilt-shift** | miniature effect / selective focus |

### Aperture & Focus
| Term | คำอธิบาย |
|------|---------|
| **f/1.4 — f/2.8** | aperture กว้าง → DOF ตื้นมาก, bokeh เยอะ |
| **f/8 — f/16** | aperture แคบ → ชัดทั้งภาพ (deep focus) |
| **Shallow depth of field** | ชัดตื้น (DOF) — โฟกัสเฉพาะจุด |
| **Deep focus** | ชัดทั้งภาพ (Citizen Kane look) |
| **Rack focus** | เลื่อนโฟกัสจากจุดหนึ่งไปอีกจุดในช็อตเดียว |
| **Bokeh / creamy bokeh** | จุดเบลอนุ่มจาก out-of-focus |

## 💡 Lighting

### Setup
| Term | คำอธิบาย |
|------|---------|
| **Three-point lighting** | key + fill + back light (มาตรฐาน) |
| **Rembrandt lighting** | แสงข้างทำให้เกิดสามเหลี่ยมแสงที่แก้ม |
| **Loop lighting** | เงาจมูกเป็นวง loop |
| **Butterfly lighting** | แสงจากบน เงาผีเสื้อใต้จมูก |
| **Rim light / back light** | แสงขอบหลัง แยกตัวจาก background |
| **Practical light** | แสงจากของในฉาก (โคมไฟ, ไฟถนน, เปลวไฟ) |
| **Motivated light** | แสงมีที่มาในเรื่อง (เห็นในภาพหรืออ้างอิงได้) |

### Mood
| Term | คำอธิบาย |
|------|---------|
| **Chiaroscuro** | แสงเงาเข้ม contrast แรง (Caravaggio painter style) |
| **Low-key lighting** | มืดเข้ม ส่วนใหญ่อยู่ในเงา (film noir) |
| **High-key lighting** | สว่างนุ่ม เงาน้อย (sitcom / commercial) |
| **Soft light / Hard light** | แสงนุ่ม (กระจาย) vs แสงคม (ตรง) |
| **Backlit / Silhouette** | ตัวละครเป็นเงาดำ |

### Color Temperature (advanced)
| Term | คำอธิบาย |
|------|---------|
| **Daylight 5600K** | แสง daylight (เขียวฟ้านิดๆ) |
| **Tungsten 3200K** | แสงไฟ tungsten (อบอุ่นส้ม) |
| **Fluorescent 4000K** | แสงเพดาน office |
| **Fire / candle 1800K** | แสงเทียน/ไฟ ส้มอบอุ่นจัด |

## ⏱️ Time-Based Prompting (Storyboard Format)

Modern AI video models รับ prompt แบบ timestamp ได้:

```
At 0s: Dragon's silhouette appears against sunset
At 2s: Dragon swoops down, wings fully extended
At 4s: Camera tracks dragon as it dives toward city
At 6s: Close-up of dragon's eyes glowing red
```

**ใช้เมื่อ**: ต้องการ control sequencing ของ action ภายในคลิป 5-8 วิ

## 🎯 Technical Specs Format (Modern Best Practice 2026)

ระบุ tech specs ตรงๆ เพื่อ precision:

```
Shot on 35mm lens, f/1.8, 24fps cinematic aesthetic, 
soft key light at 5600K, golden hour sunlight 
streaming through floor-to-ceiling windows.
```

**Components**:
- Lens: focal length + aperture (`35mm lens, f/1.8`)
- Framerate: `24fps`, `48fps`, `120fps slow-mo`
- Color temp: `5600K daylight`, `3200K tungsten`
- Light direction: `key from camera right`, `backlit silhouette`

## 🏷️ Prompt Weighting (Advanced Models)

บาง model (รวม Seedance ใหม่) รับ weighting:
```
(crimson red:1.5)        → ให้ความสำคัญ 1.5×
(soft focus:0.8)         → ลดความสำคัญ
[shaky:0.5]              → braces ลด weight
```

## 🌡️ Realism Tokens (เพิ่ม realism)

ใส่เพื่อหนีลุค "AI plastic":
- `micro-imperfections` — ผิวมีรายละเอียด ไม่เนียนเกิน
- `lens flare` — แสงสะท้อนเลนส์
- `chromatic aberration` — สีเหลื่อมขอบเลนส์
- `volumetric dust` / `volumetric light` — แสงเป็นลำ
- `light leaks` — แสงรั่วเฟรมแบบฟิล์มเก่า
- `vignette` — ขอบเฟรมมืด
- `film grain` — เกรน
- `practical effects` — เอฟเฟกต์จริงไม่ใช่ CG

## How to Use This Glossary

1. **เขียน prompt** → เปิด glossary นี้ → เลือกคำที่ตรง vision
2. **ถ้าผลแข็ง CG** → check ว่ามี 3D engine vocab ไหม → เปลี่ยนเป็น cinematography term
3. **ถ้าอยากได้ลุคหนังเฉพาะ** → ใช้ director/DP name แทนการบรรยายยาว
4. **อยาก realism** → เพิ่ม realism tokens (lens flare, grain, dust)
