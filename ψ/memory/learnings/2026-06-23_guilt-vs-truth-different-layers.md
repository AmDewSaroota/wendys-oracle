# Lesson: ความรู้สึกผิดกับความจริงอยู่คนละชั้น

**Date**: 2026-06-23
**Source**: rrr: family-finance-heart

## Pattern

เมื่อคนรู้ว่าตัวเองทำถูกต้อง (หยุดช่วยพ่อแม่ที่ไม่จัดการชีวิต) แต่ยังรู้สึกผิดอยู่ — ความรู้สึกผิดนั้นไม่ได้หายเพราะหาเหตุผลมาโต้มันได้มากพอ

ความรู้สึกผิดหายเมื่อ:
1. เวลาผ่านไป
2. เห็นซ้ำๆ ว่าการไม่ช่วยไม่ได้ทำให้โลกพัง
3. มีภาพอนาคตที่ชัดเจนเป็นสมอยึดใจ

## Application

เมื่อ DewS รู้สึกผิดเรื่องพ่อแม่ → อย่ารีบโต้ด้วยเหตุผล ให้รับรู้ความรู้สึกก่อน แล้วค่อยใช้ภาพอนาคต (4.7M / ลูกไม่ต้องกู้) เป็น anchor
