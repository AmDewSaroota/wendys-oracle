# Lesson: Dramatic ≠ Natural — ถามทิศทาง tone ก่อนเขียน action

**Date**: 2026-05-13
**Source**: Seedance prompt session — shot 1 เด็กเปิดของขวัญ

## Pattern

เมื่อ user บรรยาย action แบบ vague ("เด็กฉีกทึ้งริบบิ้น") Oracle มักตีความเป็น dramatic/intense — แต่ user อาจต้องการ natural/realistic ซึ่งต่างกันสิ้นเชิงใน AI video prompt

## บทเรียน

- **ถามก่อน**: "อยากได้ tone dramatic หรือ natural คะ?" — 5 วินาที ดีกว่าเขียนผิดทั้งก้อน
- Intensity scale ของ Seedance (เขียน 10/10 ถึงจะได้ 7/10) ใช้กับ cinematic/action — ไม่ใช่ทุก scene
- ฉากเด็กๆ / ชีวิตประจำวัน → lean toward natural description ก่อน

## Application

ทุกครั้งที่เขียน action prompt ให้ถามตัวเองก่อน:
- ฉากนี้ต้องการ **dramatic impact** หรือ **realistic feel**?
- ถ้าไม่ชัด → ถาม DewS ก่อน generate
