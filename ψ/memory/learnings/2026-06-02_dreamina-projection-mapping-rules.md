# Dreamina — Projection Mapping Room Prompt Rules

**Date**: 2026-06-02
**Project**: NDF Promo — Art In PARADISE

## Core Rules

### 1. Projection = Light Source Only
ห้องโปรเจคแมปปิ้ง = แสงบนผนัง เท่านั้น
- ไม่มีกลีบดอกลอยในอากาศ
- ไม่มี particles ในอากาศ
- ไม่มีอะไร physical ใน space
- เขียนว่า "projected blossom patterns on walls" ไม่ใช่ "petals drift through the air"

### 2. Lighting Must Be Explicit
ถ้าไม่บอก Dreamina จะ assume ambient room light:
```
Projection light only — no overhead lights, no spotlights, no ambient room light.
Projection walls are the only light source.
Light falls visibly onto visitors from the sides.
```

### 3. Walls Always Brightest
```
Walls always brightest — visitors darker, lit only by wall reflection.
```

### 4. GL Output — body language สำคัญกว่าคำ
- Dreamina อ่าน composition + body language ไม่ใช่แค่คำเดียว
- สองคนมองหน้ากัน ใกล้กัน = romantic read ไม่ว่าจะเรียกว่าอะไร
- แก้: ให้มองไปทางเดียวกัน (ผนัง/จอ), เพิ่มคนที่สามใน BG, เพิ่มระยะห่าง
- "couple" เจนออกบ้างไม่ออกบ้าง — ไม่ใช่ keyword เด็ดขาด

### 5. Dreamina Error — อย่า generalize จาก failure เดียว
ถ้า Dreamina reject → ลองตัดทีละส่วนหา culprit จริง
อย่าสรุปว่าคำหรือ section ใด flag ถ้ายังไม่ได้ test ซ้ำ
diegetic sounds ใช้งานปกติมาตลอด — ไม่ใช่ trigger

### 6. Ceiling Rule
```
Ceiling plain dark — empty, no hanging objects, no projectors visible, no equipment.
```

### 7. Floor Rule
```
Floor: abstract color wash only — no projection pattern copied to floor.
```
