# Lesson: เทียบราคา cross-platform ต้อง normalize เป็นหน่วย output

## Pattern
เวลาเทียบราคาบริการที่คิดเป็น "เครดิต" ข้ามหลายเจ้า (AI gen, cloud, ฯลฯ):
**ห้ามเทียบ ฿/เครดิต ตรงๆ** เพราะ 1 เครดิตแต่ละเจ้าให้ output ไม่เท่ากัน
(เช่น คลิปเดียวกัน Dreamina กิน 135cr แต่ Higgsfield กิน 22cr)

→ ต้อง normalize เป็น **฿ ต่อ output จริง 1 หน่วย** (฿/คลิป, ฿/รูป) = เครดิต × ฿/เครดิต
แล้วเทียบที่หน่วยนั้น

## เกณฑ์ให้แฟร์ (ล็อกให้เท่ากันทุกเจ้า)
1. output เดียวกัน (โมเดล/ความละเอียด/ความยาว/backend เดียวกัน)
2. โหมดซื้อเดียวกัน (แพลนเริ่มต้น รายเดือน · ตัดโปรชั่วคราวเป็น base)
3. สกุลเดียว (FX current) — native THB หา USD=THB/FX, native USD หา THB=USD×FX
4. วัดเครดิต/output จากของจริง (เจนจริง จดเครดิตที่หัก)

## กราฟ = ต้องแสดงผลกระทบ ไม่ใช่พล็อตข้อมูลดิบ
ถามก่อนเสมอ: "กราฟนี้ช่วยตัดสินใจอะไร / สื่อผลกระทบอะไร"
เช่น: ฿/วินาที flat (คลิปยาวไม่ลด) vs ฿/เครดิต ลดต่อ tier (ซื้อเยอะลด) = contrast มีความหมาย
ไม่ใช่แค่ "฿/คลิป vs ความยาว" ที่ขึ้นเป็นเส้นตรงตามธรรมชาติ
