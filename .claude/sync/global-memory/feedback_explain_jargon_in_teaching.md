# ห้ามใช้คำห้วน / ศัพท์วงใน เวลาเขียนเอกสารสอน

**Rule**: เวลาเขียนเอกสารสอนคนนอกวงการ → **ห้ามใช้คำย่อหรือศัพท์วงใน** ที่คนทั่วไปไม่รู้ ต้อง **อธิบายเต็มเสมอ**

**Why** (DewS feedback 2026-05-06):
- หนูเขียน "ตัด post" — DewS แก้: **"ตัด post คือ อะไร งงอ่ะ อย่าใช้คำห้วนๆ แบบนี้สิ"**
- "ตัด post" = jargon ในวงการตัดต่อ (= ครอปใน post-production)
- Oh ไม่อยู่วงการนี้ → อ่านไม่รู้เรื่อง

**คำห้วน/jargon ที่ต้องระวัง (เปิด list — เพิ่มเรื่อยๆ)**:
| ❌ ห้วน/jargon | ✅ อธิบายเต็ม |
|---------------|---------------|
| ตัด post | ครอปออกตอนตัดต่อภายหลัง (ในโปรแกรมเช่น Premiere/CapCut) |
| comp | composite / รวมภาพหลายเลเยอร์ |
| grading | color grading / ปรับสี |
| plate | ภาพต้นฉบับก่อนแต่ง |
| playblast | preview เคลื่อนไหวจาก Maya (3D animation preview) |
| rig | โครงกระดูกของตัวละคร 3D |
| FG / BG | foreground / background |
| DOF | depth of field / ระยะชัด |

**How to apply**:
- ก่อนใส่ศัพท์เทคนิค → ถาม: คนนอกวงการเข้าใจไหม?
- ถ้าไม่ชัด → **อธิบายเต็มเสมอ ใส่ตัวอย่างซอฟต์แวร์/เครื่องมือถ้าได้**
- คำที่ "หนูใช้กับ DewS ได้สบาย" ≠ "ใช้กับคนอื่นได้"
- Test: อ่านอีกรอบจากมุม Oh (ไม่อยู่วงการ AI/วิดีโอ) — ติดตรงไหน → แก้ตรงนั้น
