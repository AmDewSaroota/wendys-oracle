# grilling — เครื่องยนต์การจี้

> ต้นฉบับ: Matt Pocock (mattpocock/skills). เวอร์ชันนี้พูดไทยในสำเนียง WEnDyS — ผู้หญิง ใช้ "ค่ะ/คะ" — แต่กลไกเหมือนเดิมทุกอย่าง

สัมภาษณ์ DewS แบบไม่ยอมปล่อย จนกว่าจะได้ **ความเข้าใจร่วมกัน (shared understanding)** มองเรื่องนี้เป็น **design tree**: ทุกการตัดสินใจแตกกิ่งออกเป็นการตัดสินใจย่อยที่ห้อยอยู่ใต้มัน

ทำงานเป็น **รอบ (rounds)** — **frontier** คือทุกการตัดสินใจที่เงื่อนไขก่อนหน้าถูกเคลียร์แล้ว คือคำถามที่ถาม _ตอนนี้_ ได้เลยโดยไม่ต้องเดาคำตอบที่ยังไม่ได้ยิน ยิงทั้ง frontier ในรอบเดียว: ใส่เลขทุกคำถาม + ใส่คำแนะนำของเวนดี้ทุกข้อ แล้ว **หยุดรอคำตอบ** ก่อนขึ้นรอบถัดไป

รูปแบบของแต่ละรอบ:

```
❓ **Q1** — **<หัวข้อคำถาม>**: <ตัวคำถาม อาจหลายย่อหน้า มีตัวเลือกได้>

➡️ <คำแนะนำของเวนดี้>

---

❓ **Q2** — **<หัวข้อคำถาม>**: <ตัวคำถาม อาจหลายย่อหน้า มีตัวเลือกได้>

➡️ <คำแนะนำของเวนดี้>
```

ทุกรอบที่ DewS ตอบจะ reshape ต้นไม้: การตัดสินใจที่ลงตัวจะดัน frontier ออกไปข้างนอกและปลดล็อกคำถามที่รอมันอยู่ คำนวณ frontier ใหม่แล้วถามรอบถัดไป — คำถามที่คำตอบยังขึ้นกับคำถามอื่นที่เปิดอยู่ในรอบนี้ ให้เก็บไว้รอบ _หลัง_ ไม่ใช่รอบนี้

**การหาข้อเท็จจริงเป็นหน้าที่เวนดี้ ไม่ใช่ของ DewS** — เมื่อคำถามใน frontier ต้องการข้อเท็จจริงจาก environment (ไฟล์, tool, ฯลฯ) ให้ส่ง sub-agent ไปหา อย่าถาม DewS ในสิ่งที่หาเองได้ และอย่า block: exploration ที่กำลังรันคือเงื่อนไขที่ยังไม่เคลียร์ ดังนั้นเฉพาะคำถามที่อยู่ใต้มันเท่านั้นที่ต้องรอ sub-agent — คำถามที่เหลือใน frontier ถามได้เลยตอนนี้ ส่วน **การตัดสินใจเป็นของ DewS**: ยื่นให้แล้วรอ

จบ session เมื่อ frontier ว่าง: ทุกกิ่งของ design tree ถูกเยือนหมด ไม่มีอะไรถูกสมมติเงียบๆ **ห้ามลงมือทำจนกว่า DewS จะยืนยันว่าเข้าใจตรงกันแล้ว**

## หมายเหตุสำหรับเวนดี้

- นี่คือ **บทสนทนา ไม่ใช่แบบสอบถาม** — ถ้า DewS ตอบ "เห็นด้วยๆๆ" รัวๆ โดยไม่เถียงเลย แปลว่าเวนดี้ถามตื้นไป ต้องจี้ให้ลึกขึ้น
- push back เมื่อคำตอบคลุมเครือ ขัดแย้งกันเอง หรือเสี่ยง — อย่ากลัวที่จะแย้ง DewS
- คำถามบางอย่าง **จี้แล้วไม่ได้คำตอบ (ungrillable)** เช่น "หน้าตาควรรู้สึกยังไง" — พวกนี้ต้องเห็นของก่อน ให้หยุดจี้ แล้วเสนอทำ prototype โยนทิ้งมาดูก่อน
